Bub 0.6.0 将 Agent 内核依赖与应用依赖分开。升级 CLI 安装、插件或发行版时，请加入 `app` extra。

## 更新应用安装

通过 `uv tool` 安装的应用使用：

```bash
uv tool install --upgrade --force "bub[app]"
```

已经激活的应用虚拟环境使用：

```bash
uv pip install --upgrade "bub[app]"
```

插件或发行版的 `pyproject.toml` 也应把普通 `bub` 依赖改为 `bub[app]>=0.6.0`。这个 extra 安装内置运行时、Framework、配置、插件 hooks、skills 和渠道所需的依赖。

运行 `bub --help`，再[完成一轮对话](/zh-cn/docs/app/first-session/)。检查插件是否加载时，使用 `bub hooks`。

## 按代码用途选择接口

| 代码用途 | 依赖与指南 |
| --- | --- |
| 直接向 `core.Agent` 传入模型和工具 | `bub`；[构建自己的 Agent](/zh-cn/docs/sdk/) |
| 使用 `BubAgent`、Framework、应用 hooks 或渠道 | `bub[app]`；[定制 Bub 应用](/zh-cn/docs/app/) |

直接组合的 Agent 在 Python 中接收模型与组件。Bub 应用通过 `BubAgent` 和 Framework 提供配置、skills 与工具策略。[工具](/zh-cn/docs/sdk/tools/)和 [Agent 事件](/zh-cn/docs/concepts/events/)说明共同契约与默认行为的区别。
