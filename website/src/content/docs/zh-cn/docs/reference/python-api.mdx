本页按模块列出 Bub 公开的 Python 类与函数签名，并用表格说明其参数、属性与方法。分步使用教程见 [SDK 指南](/zh-cn/docs/sdk/)、[Tape](/zh-cn/docs/concepts/tape/)、[事件](/zh-cn/docs/concepts/events/) 与 [Turn](/zh-cn/docs/concepts/turn/)。

- **`bub.core`**：核心层，包含 `Agent` 循环、模型客户端协议、工具、Tape 与事件总线。仅导入 `bub.core` 不会读取 YAML 配置文件、`BUB_*` 环境变量，也不会加载 CLI 或插件。
- **`bub`**：应用层，包含 `BubFramework`、`BubAgent`、消息渠道与配置加载。需要[安装](/zh-cn/docs/getting-started/install/) `bub[app]` 可选依赖。

签名中出现的 `republic.*` 类型来自底层依赖包 Republic，本页不单独展开。

## 核心层 {#core}

### `Agent` {#agent}

```python
from bub.core import Agent

class Agent:
    tools: dict[str, Tool]
    builtin_tools: list[BuiltinTool]
    system_prompt: SystemPrompt
    events: EventBus

    def __init__(
        self,
        *,
        model: Model | None = None,
        store: TapeStore | AsyncTapeStore | None = None,
        tools: Iterable[Tool | BuiltinTool] = (),
        system_prompt: SystemPrompt | PromptSection | Iterable[PromptSection] = (),
        context: TapeContext | None = None,
        sidecars: Sequence[TapeSidecar] = (),
        max_steps: int = sys.maxsize,
        max_tool_concurrency: int | None = None,
        name: str = "agent",
        command_prefix: str | None = None,
    ) -> None: ...

    def tape(self, name: str, *, state: TurnState | None = None) -> Tape: ...

    @asynccontextmanager
    async def session(
        self,
        name: str,
        *,
        state: TurnState | None = None,
        merge_back: bool = True,
    ) -> AsyncGenerator[Tape]: ...

    @asynccontextmanager
    async def run(
        self,
        prompt: str | list[UserContent],
        *,
        model: Model | None = None,
        options: Mapping[str, Any] | None = None,
        tape: str,
        state: TurnState | None = None,
        merge_back: bool = True,
        metadata: dict[str, Any] | None = None,
    ) -> AsyncGenerator[AsyncStreamEvents]: ...

    async def start(
        self,
        prompt: str | list[UserContent],
        *,
        model: Model | None = None,
        options: Mapping[str, Any] | None = None,
        tape: str,
        state: TurnState | None = None,
        merge_back: bool = True,
        metadata: dict[str, Any] | None = None,
    ) -> AsyncStreamEvents: ...

    async def run_on(
        self,
        tape: Tape,
        prompt: list[UserContent],
        *,
        model: Model | None = None,
        options: Mapping[str, Any] | None = None,
        metadata: dict[str, Any] | None = None,
        span: Span | None = None,
        on_close: Callable[[], Awaitable[None]] | None = None,
    ) -> AsyncStreamEvents: ...

    async def run_once(
        self,
        prompt: list[UserContent] | None,
        *,
        model: Model | None = None,
        options: Mapping[str, Any] | None = None,
        tape: Tape,
        state: StreamState | None = None,
        pending: Sequence[list[UserContent]] = (),
    ) -> AsyncGenerator[StreamEvent, None]: ...

    async def run_command(self, tape: Tape, line: str) -> str: ...

    async def prepare_tools(
        self,
        tape: Tape,
        prompt: list[UserContent] | None,
    ) -> list[Tool]: ...
```

**构造函数参数**（`Agent.__init__`）：

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `model` | `Model \| None` | `None` | 默认模型连接（`republic.ChatModel` 或 `ModelClient`）；也可在每次调用 `run()` 时单独传入 |
| `store` | `TapeStore \| AsyncTapeStore \| None` | 新的 `InMemoryTapeStore()` | 会话历史存储后端，支持同步或异步实现 |
| `tools` | `Iterable[Tool \| BuiltinTool]` | `()` | 本地 `Tool` 对象（存入 `agent.tools`）或提供商侧执行的工具如 `republic.tools.WebSearch()`（存入 `agent.builtin_tools`）；同名工具后传入的覆盖前面的 |
| `system_prompt` | `SystemPrompt \| PromptSection \| Iterable[PromptSection]` | `()` | 系统提示词；每次 Run 在第一个模型 Step 前渲染一次，并在后续 Step 中复用 |
| `context` | `TapeContext \| None` | `default_tape_context()` | 控制如何从 Tape 历史条目投影出模型上下文消息 |
| `sidecars` | `Sequence[TapeSidecar]` | `()` | 随主 Tape 一起挂载的附属 `TapeSidecar` 列表 |
| `max_steps` | `int` | `sys.maxsize` | 单次 Run 允许的最大 Step 数 |
| `max_tool_concurrency` | `int \| None` | `None` | 单步响应内并发执行本地工具的最大数量（`1` 表示串行执行；不控制不同 Run 之间的并发） |
| `name` | `str` | `"agent"` | OpenTelemetry trace span 中显示的 Agent 名称 |
| `command_prefix` | `str \| None` | `None` | 直接命令前缀（`None` 表示禁用；启用时须为非空且不含空白的字符串，如 `","`） |

**运行参数**（`Agent.run` / `Agent.start`）：

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `prompt` | `str \| list[UserContent]` | 必填 | 本次发送给 Agent 的用户提示词或多模态内容列表 |
| `model` | `Model \| None` | `self.model` | 覆盖本次 Run 使用的模型连接 |
| `options` | `Mapping[str, Any] \| None` | `None` | 传给底层模型生成调用的参数（对应 `republic.ChatOptions`，如 `max_tokens`、`reasoning_effort`） |
| `tape` | `str` | 必填 | 本次 Run 使用的会话 Tape 名称 |
| `state` | `TurnState \| None` | `None` | 本次 Run 内供工具和事件处理器共享的临时字典 |
| `merge_back` | `bool` | `True` | 流关闭时是否将本次 Run 在分支上写入的记录合并回主 Tape（详见[分支合并策略](/zh-cn/docs/sdk/tape/#forks-and-merges)） |
| `metadata` | `dict[str, Any] \| None` | `None` | 随 `RunStarted` 事件发出的调用元数据，不进入模型上下文 |

**核心方法说明**：

| 方法 | 说明 |
| --- | --- |
| `run(...)` | 异步上下文管理器：在命名 Tape 的分支上启动一次 Run，退出 `async with` 时自动关闭流并按 `merge_back` 合并记录 |
| `start(...)` | 与 `run(...)` 参数一致，但直接返回 `AsyncStreamEvents`，需由调用方手动调用 `await stream.aclose()` |
| `tape(name, *, state=None)` | 返回指定名称的 `Tape` 读写视图（不会自动写入 `session/start` 初始锚点） |
| `session(name, *, state=None, merge_back=True)` | 异步上下文管理器：打开指定 Tape 的临时分支并在退出时按 `merge_back` 合并 |
| `run_on(tape, prompt, ...)` | 在一个已经打开的 `Tape` 实例上运行一次 Run |
| `run_once(...)` | 仅执行单个模型 Step 及其请求的全部工具调用 |
| `run_command(tape, line)` | 直接执行一条带命令前缀的工具命令，不调用模型 |
| `prepare_tools(tape, prompt)` | 供子类覆写：每次 Run 开始时调用一次以决定可用工具集；若运行中调用了未在初始集合内的延迟工具，则通过 `prepare_tools(tape, None)` 重新解析 |

### `Model`、`ModelClient` 与 `ChatModelClient` {#model}

```python
from bub.core import ChatModelClient, Model, ModelClient

type Model = republic.ChatModel | ModelClient

class ModelClient(Protocol):
    max_tokens: int | None

    @property
    def spec(self) -> str: ...

    def open_stream(
        self,
        messages: list[republic.Message],
        *,
        spec: str,
        options: Mapping[str, Any],
    ) -> AbstractAsyncContextManager[tuple[str, republic.Stream[Any]]]: ...

class ChatModelClient:
    max_tokens: int | None = None

    def __init__(self, model: republic.ChatModel) -> None: ...

    @property
    def spec(self) -> str: ...

    @asynccontextmanager
    async def open_stream(
        self,
        messages: list[republic.Message],
        *,
        spec: str,
        options: Mapping[str, Any],
    ) -> AsyncIterator[tuple[str, republic.Stream[Any]]]: ...
```

| 成员 / 参数 | 类型 | 说明 |
| --- | --- | --- |
| `spec` | `str` | 模型规格标识符（格式为 `provider:model`） |
| `max_tokens` | `int \| None` | 默认的最大输出 Token 数；单次调用的 `options["max_tokens"]` 优先 |
| `open_stream(messages, *, spec, options)` | 异步上下文管理器 | 打开一次模型流式请求，产出一个 `(resolved_spec, republic_stream)` 元组 |
| `ChatModelClient(model)` | `republic.ChatModel` | 将 `republic.ChatModel` 包装为 `ModelClient` 的内置适配器；底层连接生命周期仍由调用方管理 |

### `Tool`、`ToolContext` 与 `@tool` {#tools}

```python
from bub.core import Tool, ToolContext, tool
from bub.core.tools import ToolExposure, content_result, result_content

type ToolExposure = Literal["auto", "direct", "code", "command"]

@dataclass(frozen=True)
class ToolContext:
    tape: Tape
    run_id: str | None = None
    state: dict[str, Any] = field(default_factory=dict)
    code_mode: bool = False
    command: bool = False
    events: EventBus | None = field(default=None, repr=False, compare=False)
    step_messages: list[republic.Message] = field(default_factory=list, repr=False, compare=False)
    call_id: str | None = None

@dataclass(frozen=True)
class Tool:
    name: str
    handler: Callable[..., Any]
    description: str = ""
    parameters: dict[str, Any] = field(default_factory=dict)
    context: bool = False
    exposure: ToolExposure = "auto"
    renderer: Callable[[Any], str] | None = None
    output_schema: dict[str, Any] | None = None
    deferred: bool = False

    async def run(self, *args: Any, **kwargs: Any) -> Any: ...
    def render(self, result: Any) -> str: ...
    def to_schema(self) -> dict[str, Any]: ...

    @classmethod
    def from_callable(
        cls,
        func: Callable[..., Any],
        *,
        name: str | None = None,
        description: str | None = None,
        context: bool = False,
        exposure: ToolExposure = "auto",
        renderer: Callable[[Any], str] | None = None,
        deferred: bool = False,
    ) -> Tool: ...

def tool(
    func: Callable | None = None,
    *,
    name: str | None = None,
    model: type[BaseModel] | None = None,
    description: str | None = None,
    context: bool = False,
    exposure: ToolExposure = "auto",
    renderer: Callable[[Any], str] | None = None,
    deferred: bool = False,
) -> Tool | Callable[[Callable], Tool]: ...

def content_result(content: Sequence[UserContent]) -> dict[str, Any]: ...
def result_content(result: Any) -> list[UserContent]: ...
```

**`@tool` / `Tool` 参数与字段说明**：

| 参数 / 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `func` / `handler` | `Callable[..., Any]` | 必填 | 实际执行工具逻辑的同步或异步 Python 函数 |
| `name` | `str \| None` | 函数名 `func.__name__` | 工具名称（含点号的名称在暴露给模型时会自动转为下划线别名） |
| `model` | `type[BaseModel] \| None` | `None` | 可选的 Pydantic 参数校验模型（仅用于 `@tool(model=...)` 装饰器） |
| `description` | `str \| None` | 函数的 docstring | 工具的功能描述，供模型判断何时调用 |
| `parameters` | `dict[str, Any]` | 自动从类型标注生成 | 工具入参的 JSON Schema 字典 |
| `context` | `bool` | `False` | 设为 `True` 时，运行时会自动向函数注入关键字参数 `context: ToolContext`（该参数不会出现在模型可见的 Schema 中） |
| `exposure` | `ToolExposure` | `"auto"` | 工具暴露方式：`"auto"`（模型直调、代码模式与命令均可用）、`"direct"`（仅模型直调）、`"code"`（仅在 `run_code` 内可调）、`"command"`（仅作为文本命令可调） |
| `renderer` | `Callable[[Any], str] \| None` | `None` | 自定义将工具返回值渲染为字符串的转换函数 |
| `output_schema` | `dict[str, Any] \| None` | 自动从返回类型生成 | 返回值的 JSON Schema（供代码模式生成类型桩文件使用） |
| `deferred` | `bool` | `False` | 是否启用延迟加载：设为 `True` 时初始仅向模型展示名称与简述，模型按需通过 `tool.describe` 加载完整 Schema |

**`ToolContext` 字段说明**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `tape` | `Tape` | 当前会话的 `Tape` 读写对象 |
| `run_id` | `str \| None` | 当前 Run 的唯一标识符 |
| `state` | `dict[str, Any]` | 当前调用共享的 `TurnState` 字典 |
| `code_mode` | `bool` | 本次工具调用是否由代码模式内部发起 |
| `command` | `bool` | 本次工具调用是否由直接命令发起 |
| `events` | `EventBus \| None` | 当前 Agent 的事件总线 |
| `step_messages` | `list[republic.Message]` | 发起本次工具调用的那个模型 Step 所发送的用户消息（这些消息在当前 Step 的工具全部执行完后才写入 Tape） |
| `call_id` | `str \| None` | 模型为本次调用分配的 ID（代码模式内部发起的工具调用会沿用外层 `run_code` 的 `call_id`） |

`content_result(content)` 用于在工具返回值中同时携带文本与图片、音频或视频，投影上下文时由 `result_content(result)` 还原为多模态内容块（详见[媒体内容的存储边界](/zh-cn/docs/sdk/tape/#media)）。

### `SystemPrompt`、`PromptSection` 与 `PromptContext` {#system-prompt}

```python
from bub.core import PromptContext, PromptSection, SystemPrompt

@dataclass(frozen=True)
class PromptContext:
    agent: Agent
    tape: Tape
    prompt: list[UserContent]
    tools: list[Tool]
    model: str

    @property
    def state(self) -> TurnState: ...

    @property
    def available_tools(self) -> list[Tool]: ...

type PromptSection = str | Callable[[PromptContext], str | Awaitable[str | None] | None]

class SystemPrompt:
    def __init__(self, sections: Iterable[PromptSection] = ()) -> None: ...

    @classmethod
    def of(
        cls,
        value: SystemPrompt | PromptSection | Iterable[PromptSection],
    ) -> SystemPrompt: ...

    @property
    def sections(self) -> tuple[PromptSection, ...]: ...

    def add(self, section: S) -> S: ...
    def remove(self, section: PromptSection) -> None: ...
    async def render(self, context: PromptContext) -> str: ...
```

| 类 / 成员 | 说明 |
| --- | --- |
| `PromptSection` | 一段固定字符串，或接收 `PromptContext` 并返回 `str \| None` 的同步/异步函数 |
| `SystemPrompt.add(section)` / `remove(section)` | 动态追加或移除一段系统提示词片段 |
| `await SystemPrompt.render(context)` | 按顺序执行所有片段，将非空文本用换行拼接为最终系统提示词 |
| `PromptContext` | 渲染时传入的上下文，提供当前 `agent`、`tape`、`prompt`、`tools`、`model`，以及便捷属性 `state` 与 `available_tools` |

### `Tape`、`TapeContext` 与存储 {#tape}

```python
from bub.core import Tape, TapeContext, default_tape_context, session_tape_name
from bub.core.tape import AnchorSummary, TapeEntry, TapeInfo

@dataclass(frozen=True)
class TapeContext:
    anchor: AnchorSelector = LAST_ANCHOR
    select: ContextSelector | None = None
    state: dict[str, Any] = field(default_factory=dict)

    def build_query(self, query: TapeQuery) -> TapeQuery: ...

def default_tape_context() -> TapeContext: ...
def session_tape_name(session_id: str, workspace: Path) -> str: ...

@dataclass(frozen=True)
class TapeInfo:
    name: str
    entries: int
    anchors: int
    last_anchor: str | None
    entries_since_last_anchor: int
    last_token_usage: int | None
    last_token_cache_hit_rate: float | None

@dataclass(frozen=True)
class AnchorSummary:
    name: str
    state: dict[str, object]

@dataclass(frozen=True)
class Tape:
    store: AsyncTapeStore
    context: TapeContext
    sidecars: tuple[TapeSidecar, ...] = field(default=(), repr=False)

    @property
    def name(self) -> str: ...

    def with_context(self, context: TapeContext) -> Tape: ...
    def scoped(self, name: str, context: TapeContext | None = None) -> Tape: ...
    def query(self) -> TapeQuery[AsyncTapeStore]: ...
    async def info(self) -> TapeInfo: ...
    async def anchors(self, limit: int = 20) -> list[AnchorSummary]: ...
    async def search(self, query: TapeQuery[AsyncTapeStore]) -> list[TapeEntry]: ...
    async def append_event(self, name: str, payload: dict[str, Any], **meta: Any) -> None: ...
    async def read_messages(self) -> list[republic.Message]: ...

    async def handoff(
        self,
        *,
        name: str,
        state: dict[str, Any] | None = None,
        **meta: Any,
    ) -> list[TapeEntry]: ...

    async def reset(
        self,
        *,
        state: dict[str, Any] | None = None,
        keep_sidecars: Iterable[str] = (),
    ) -> None: ...

    @asynccontextmanager
    async def fork_tape(self, merge_back: bool = True) -> AsyncGenerator[Tape, None]: ...
```

**`TapeContext` 字段说明**：

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `anchor` | `AnchorSelector` | `LAST_ANCHOR` | 上下文读取的起始锚点：默认从最近一个 anchor 之后读取；可传具体 anchor 名称字符串，或传 `None` 从头读取全部条目 |
| `select` | `ContextSelector \| None` | `None` | 自定义投影选择器函数 `(Iterable[TapeEntry], TapeContext) -> list[republic.Message]`。建议使用 `default_tape_context()` 工厂函数以支持完整对话与工具往返 |
| `state` | `dict[str, Any]` | `{}` | 绑定在该上下文上的请求级临时状态字典（即 `TurnState`） |

**`Tape` 属性与方法说明**：

| 属性 / 方法 | 说明 |
| --- | --- |
| `name` | 当前 Tape 的名称；若直接构造 `Tape` 而未调用 `scoped(name)`，访问该属性会抛出 `ValueError` |
| `scoped(name, context=None)` | 返回绑定了指定 `name`（及可选新 `context`）的 `Tape` 视图 |
| `with_context(context)` | 返回替换了 `TapeContext` 的新 `Tape` 视图（适合单次临时换一种投影方式读取） |
| `query()` | 返回绑定了当前 Tape 与 `store` 的 `TapeQuery` 查询构建器 |
| `await read_messages()` | 按当前 `TapeContext` 筛选条目并投影为 `list[republic.Message]`（自动排除 `meta["context"] is False` 的条目） |
| `await handoff(*, name, state=None, **meta)` | 追加一条 `anchor` 条目和一条 `handoff` 事件，将默认上下文读取起点前移到此处 |
| `await reset(*, state=None, keep_sidecars=())` | 清空当前 Tape 记录并重新写入 `session/start` 锚点；默认同时重置所有已挂载的 Sidecar |
| `await info()` / `await anchors(limit=20)` | 分别返回 `TapeInfo` 统计信息和 `list[AnchorSummary]` 历史锚点列表 |
| `await search(query)` | 执行传入的 `TapeQuery` 并返回匹配的 `list[TapeEntry]` |
| `await append_event(name, payload, **meta)` | 向 Tape 显式追加一条 `kind="event"` 的业务事件记录 |
| `fork_tape(merge_back=True)` | 异步上下文管理器：在临时分支上读写，退出时默认将新条目合并回主 Tape |

`session_tape_name(session_id, workspace)` 生成 `<workspace hash>__<session hash>` 格式的物理 Tape 名称，供应用层隔离不同工作区下的会话。

#### `TapeSidecar` {#tapesidecar}

```python
from bub.core.sidecars import TapeSidecar, sidecar_tape_name

    @property
    def name(self) -> str: ...
```

#### `TapeStore` 与 `AsyncTapeStore` {#tape-store}

```python

    async def reset(self, tape: str) -> None: ...
```

| 方法 | 实现契约 |
| --- | --- |
| `list_tapes()` | 返回已存在的会话 Tape 名称列表（无需列出 sidecar 等内部物理 Tape） |
| `append(tape, entry)` | 追加条目，并在该 Tape 内分配从 `1` 开始单调递增的 `id`（不要依赖调用方传入的 `entry.id`） |
| `fetch_all(query)` | 按写入顺序返回符合 `TapeQuery` 条件的条目集合（异步版本是 `async def` 返回 `Iterable`，而非异步生成器） |
| `reset(tape)` | 清空该 Tape 的所有记录并重置 ID 计数，使下一次 `append` 重新从 `1` 开始 |

#### `TapeQuery` {#tapequery}

```python
@dataclass(frozen=True)
class TapeQuery[T: TapeStore | AsyncTapeStore]:
    tape: str
    store: T

    def query(self, value: str) -> Self: ...
    def after_anchor(self, name: str) -> Self: ...
    def last_anchor(self) -> Self: ...
    def between_anchors(self, start: str, end: str) -> Self: ...
    def between_dates(self, start: str | date_type, end: str | date_type) -> Self: ...
    def kinds(self, *kinds: str) -> Self: ...
    def limit(self, value: int) -> Self: ...

    @overload
    def all(self: TapeQuery[TapeStore]) -> Iterable[TapeEntry]: ...
    @overload
    async def all(self: TapeQuery[AsyncTapeStore]) -> Iterable[TapeEntry]: ...
```

| 方法 | 过滤语义 |
| --- | --- |
| `query(value)` | 在条目的 `kind`、`date`、`payload` 和 `meta` 的 JSON 文本中做不区分大小写的包含匹配 |
| `after_anchor(name)` / `last_anchor()` | 返回指定名称或最近一个 anchor **之后**的条目（不含该边界 anchor 本身）；若找不到对应 anchor 则抛出 `BubError(kind=NOT_FOUND)` |
| `between_anchors(start, end)` | 返回两个 anchor 之间的条目（不含两端边界）；任一 anchor 不存在时抛出 `BubError(kind=NOT_FOUND)` |
| `between_dates(start, end)` | 按 ISO 日期或时间范围过滤（含边界；只传日期时上界覆盖整天） |
| `kinds(*kinds)` | 只保留指定 `kind` 的条目 |
| `limit(value)` | 最多返回的条目数（在其他过滤条件生效后截断） |
| `all()` | 执行查询（同步 Store 直接返回 `Iterable`，异步 Store 需 `await`） |

#### 事件一览 {#event-reference}

| 事件类 | 触发时机 | 处理器可读取或修改的字段 |
| --- | --- | --- |
| `RunStarted` | 模型 Run 启动时 | `model`、`prompt`、`metadata`、`tape`、`state` |

| `StepStarted` | 单个 Step 开始时 | `step`、可选的 `prompt` |
| `StepFinished` | 单个 Step 结束时 | `step`、`status`、`elapsed_ms`、`stream`；可在继续下一步时设置 `next_prompt` |
| `MessagesPending` | 构建请求前，或某步结束且无工具调用时 | 向 `messages` 追加运行期间到达的用户消息；在步末追加会让 Run 继续下一步 |
| `LLMCallStarted` | 调用模型提供商之前 | 替换 `request`；或设置 `decision = LLMCallDecision.finish(text)` |
| `LLMCallFinished` | 模型调用成功或因普通异常失败后 | `request` 与汇总后的 `result` |
| `ToolCallStarted` | 本地工具执行之前 | 替换 `call`；或设置 `decision`（`proceed` / `deny` / `replace`） |
| `ToolCallFinished` | 工具成功、失败、被拒绝或被替代后 | `call` 与 `result`（可给 `event.result.result` 赋值以替换面向模型的结果） |
| `ChatFinished` | 当前 Step 的对话和工具往返准备写入 Tape 时 | `new_messages`、`response_text`、`tool_calls`、`tool_results`、`usage`、`error` |
| `CommandFinished` | 直接命令执行成功或失败时 | `line`、`name`、`status`、`elapsed_ms`、`output` |

- `RunFinished` 在事件流关闭时发出；尚未迭代就关闭的 Run 以 `status="cancelled"`、`steps=0` 结束。`LLMCallFinished` 和 `ToolCallFinished` 不保证覆盖外部取消路径。
- 步数超过 `max_steps`（应用层由 `BUB_MAX_STEPS` 控制）时抛出 `max_steps_reached` 错误。
- 直接命令触发工具事件和 `CommandFinished`，不触发 `RunStarted` 或 `RunFinished`。
- 拦截载荷（`LLMCallRequest`、`LLMCallDecision`、`ToolCall`、`ToolCallDecision` 等）的字段定义见 [Hooks 参考](/zh-cn/docs/reference/hooks/#interception-payloads)（事件与 Hook 的映射关系见 [Hooks 事件映射](/zh-cn/docs/reference/hooks/#event-mapping) 与 [Agent 事件](/zh-cn/docs/concepts/events/#call-control)）。

| `is_running()` | 检查进程或其子孙进程是否仍在运行 |

#### `run_code` 契约 {#run-code-contract}

- `code` 支持顶层 `await`；`tools` 中的工具在代码里通过 `await tools.<name>(**kwargs)` 调用，底层转发给 `await call_tool(name, kwargs)`（代码也可通过 `call_tool` 调用 `republic.` 前缀的媒体与模型辅助方法）。
- 标准输出必须在产生时立即回调 `write(chunk)`，以确保超时后仍能保留已产生的输出。
- 代码自身抛错时抛出 `CodeFailed(error, traceback)`；有 Python 解释器的自定义环境可直接复用 `bub.core.codemode.runner.run_code_in_subprocess(self, ...)`。

#### `CodeFailed` {#codefailed}

```python
class CodeFailed(Exception):
    def __init__(self, error: str, traceback: str = "") -> None: ...
```

`error` 为 `"<异常类型>: <消息>"`，`traceback` 为仅包含模型代码自身栈帧的回溯字符串。

#### 环境在应用层中如何提供 {#provide-an-environment}

应用层通过 `provide_environment(session_id, workspace)` Hook 为每个会话缓存一个 `Environment`（默认返回 `LocalEnvironment(workspace)`），写入 `TurnState[ENVIRONMENT_STATE_KEY]` 并在 `framework.running()` 退出时调用 `close()`。

:::caution
`LocalEnvironment` 直接在宿主机上执行进程与读写文件，**单独的子进程不是安全沙箱**。执行不受信任的代码时，请实现具备文件系统、网络与权限隔离的 `Environment`。
:::
