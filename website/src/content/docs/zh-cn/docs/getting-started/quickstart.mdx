自 0.6.0 版本起，Bub 本体拆分成了两部分，因此你可以根据需要选择使用哪部分来玩转 Bub。

这一页假设你已经[安装 Bub](/zh-cn/docs/getting-started/install/)。

## 从 CLI 启动 {#cli}

打开你系统的终端，然后按如下步骤在命令行中进行操作：

<Steps>

1. 如果你从未配置过 Bub，可以先执行如下命令来完成初始配置：

   ```bash
   bub onboard
   ```

2. 在任意目录中创建一个工作区（目录）并切换到当中，然后使用 `bub chat` 启动一个交互式会话：

   ```bash
   mkdir hello-bub && cd hello-bub
   bub chat
   ```

   :::tip
   运行命令前，可输入 `bub --help` 查看命令和选项，或查阅 [CLI 参考](/zh-cn/docs/reference/cli/)。
   :::

3. 现在，可以尝试复制粘贴如下文本并与 Bub 进行对话：

   ```shell
   Summarize the files in this directory
   ```

</Steps>

在交互式的 CLI 界面中，使用 <kbd>Ctrl+D</kbd> 或输入 `,quit` 退出交互式会话。

## 用 SDK 运行 {#sdk}

如果要把 Agent 嵌入自己的 Python 项目，可以从基础 SDK 开始。

<Steps>

1. 创建新项目并安装 Bub：

   ```bash
   uv init --python 3.12 my-agent && cd my-agent
   uv add bub
   ```

2. 把下面这段代码保存为 `main.py`

   ```python
   import asyncio

   import republic

   from bub.core import Agent


   async def main() -> None:
       agent = Agent(system_prompt="Be concise.")
       async with republic.get_model("openai:gpt-5-mini") as model:
           async with agent.run("What can you do?", model=model, tape="demo") as stream:
               async for event in stream:
                   if event.kind == "text":
                       print(event.data.get("delta", ""), end="")


   asyncio.run(main())
   ```

   :::tip
   查阅 [Python API](/zh-cn/docs/reference/python-api/) 以了解更多 API 接口。
   :::

3. 用你的 API Key 跑起来

   ```bash
   export REPUBLIC_OPENAI_API_KEY=sk-...
   uv run python main.py
   ```

</Steps>
