自 0.6.0 版本起，Bub 本体拆分成了核心层与应用层两部分，你可以按自己的习惯选择其中一种方式来玩转 Bub。

开始前，这一页假设你已经[安装好 Bub](/zh-cn/docs/getting-started/install/)。

## 从 CLI 启动 {#cli}

打开你的终端，跟着下面几步在命令行里试试看：

<Steps>

1. （可选）如果你从未配置过 Bub，可以先运行配置向导完成初始配置：

   ```bash
   bub onboard
   ```

2. 在任意位置创建一个工作区目录并切换进去，然后用 `bub chat` 启动交互式会话：

   ```bash
   mkdir hello-bub && cd hello-bub
   bub chat
   ```

   :::tip
   运行 `bub --help` 或查阅 [CLI 参考](/zh-cn/docs/reference/cli/) 了解所有命令选项。
   :::

3. 现在，试着复制粘贴下面这句话，和 Bub 聊一聊：

   ```shell
   Summarize the files in this directory
   ```

</Steps>

在交互式 CLI 界面中，按 <kbd>Ctrl+D</kbd> 或输入 `,quit` 即可退出会话。

## 用 SDK 运行 {#sdk}

如果你想把 Agent 嵌入自己的 Python 项目，可以从基础 SDK 开始：

<Steps>

1. 创建新项目并安装 `bub`：

   ```bash
   uv init --python 3.12 my-agent && cd my-agent
   uv add bub
   ```

2. 把下面这段代码保存为 `main.py`：

   ```python title="main.py" {9-11}
   import asyncio

   import republic

   from bub.core import Agent


   async def main() -> None:
       agent = Agent(system_prompt="Be concise.")
       async with republic.get_model("openai:gpt-5-mini") as model:
           async with agent.run("What can you do?", model=model, tape="demo") as stream:
               async for event in stream:
                   if event.kind == "text":
                       print(event.data.get("delta", ""), end="")


   asyncio.run(main())
   ```

   :::tip
   完整接口说明见 [Python API 参考](/zh-cn/docs/reference/python-api/)。
   :::

3. 用你的 API Key 跑起来：

   ```bash
   export REPUBLIC_OPENAI_API_KEY=sk-...
   uv run python main.py
   ```

</Steps>
