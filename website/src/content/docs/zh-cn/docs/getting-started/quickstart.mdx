Bub 有两种跑法：作为独立进程的应用，或作为 Python 程序里的库。两者跑的是同一套内核，之后可以随时换。

这一页假设你已经[安装 Bub](/zh-cn/docs/getting-started/install/)。

## 跑起来

<Tabs syncKey="form">
<TabItem label="使用 Bub 应用">

先配置一次模型，然后在任意项目目录里开始对话：

```bash
bub onboard
```

```bash
mkdir hello-bub && cd hello-bub
bub chat
```

问它一个问题：

```text
> Summarize the files in this directory
```

目录里有 `AGENTS.md` 时 Bub 会读取它，把这次 turn 记到 tape 上，再用你配置的模型回答。按 `Ctrl+C` 退出。

下一步：[工作区](/zh-cn/docs/app/workspace/)讲 `AGENTS.md` 和应用的命令。

</TabItem>
<TabItem label="构建你的 Bub Agent">

在自己的项目里添加 Bub，然后自己驱动循环：

```bash
uv init --python 3.12 my-agent && cd my-agent
uv add bub
```

把这段保存为 `main.py`：

```python
import asyncio

import republic

from bub.core import Agent


async def main() -> None:
    agent = Agent(system_prompt="Be concise.")
    async with republic.get_model("openai:gpt-5-mini") as model:
        async with agent.run("What can you do?", model=model, tape="demo") as stream:
            async for event in stream:
                if event.kind == "text":
                    print(event.data.get("delta", ""), end="")


asyncio.run(main())
```

```bash
export REPUBLIC_OPENAI_API_KEY=sk-...
uv run python main.py
```

`Agent` 负责模型与工具循环；模型、工具和 tape 名字由你传入。事件流里 `text` 是回答，模型调用工具时还会有 `tool_call` 和 `tool_result`。

下一步：[构建你的 Bub Agent](/zh-cn/docs/sdk/)会加一个工具，并讲清事件流的生命周期。

</TabItem>
