Bub 有 CLI 和 SDK 两种使用方式，你可以根据自己的需求选择对应的安装途径。

## 安装 CLI 应用 {#app-install}

<Tabs syncKey="bub-app-install">
<TabItem label="macOS / Linux">

```bash
curl -fsSL https://bub.build/install.sh | bash
```

</TabItem>
<TabItem label="Windows">

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://bub.build/install.ps1 | iex"
```

</TabItem>
<TabItem label="uv">

```bash
uv tool install "bub[app]"
uv tool update-shell
```

</TabItem>
</Tabs>

使用安装脚本时，它会自动安装 `uv` 和 Python 3.12，并把 `bub[app]` 安装到当前环境中。`app` 是 Bub 的可选依赖组，包含 CLI、消息渠道和插件等应用层能力；如果只使用 SDK，则不需要它。

安装完成后，先运行 `bub --help` 验证一下，再执行 `bub onboard` 开始初始配置。

:::tip
如果提示找不到 `bub` 命令，请检查环境变量是否包含了可执行文件所在路径，或手动将 `~/.local/bin` 加入 `PATH`。
:::

## 安装 SDK {#agent-install}

自 0.6.0 起，`bub` 包默认只包含核心层。用你习惯的包管理器把它添加到项目中即可，这里以 `uv` 为例：

```bash
uv add bub
uv run python -c "from bub.core import Agent; print(Agent.__name__)"
```

## 从源码运行 {#from-source}

克隆项目仓库，按如下步骤同步依赖即可：

```bash
git clone https://github.com/bubbuild/bub.git
cd bub
uv sync
```

之后执行 `uv run bub` 运行即可。
