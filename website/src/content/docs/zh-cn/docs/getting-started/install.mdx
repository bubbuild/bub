按你的使用方式选择安装路径。Python 项目通过 [uv](https://docs.astral.sh/uv/getting-started/installation/) 添加 Bub；运行应用可以使用安装脚本或 uv。

<a id="app-install"></a>

## 运行 Bub 应用

选择适合你的安装方式：

<Tabs syncKey="bub-app-install">
<TabItem label="macOS / Linux">

```bash
curl -fsSL https://bub.build/install.sh | bash
```

</TabItem>
<TabItem label="Windows">

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://bub.build/install.ps1 | iex"
```

</TabItem>
<TabItem label="uv">

```bash
uv tool install "bub[app]"
uv tool update-shell
```

打开新终端后，运行 `bub onboard` 配置模型和渠道。

</TabItem>
</Tabs>

脚本会按需安装 uv 和 Python 3.12，并将 `bub[app]` 安装到 `~/.bub/.venv`。按提示选择插件预设，再完成模型和渠道配置。

安装结束后，确认命令目录已加入 PATH，再检查：

```bash
bub --help
```

接着看[工作区](/zh-cn/docs/app/workspace/)，建一个工作区，写下项目指令。

基础安装与 `bub[app]` 包含相同的包文件；extra 改变的是安装的依赖。缺少应用依赖时，`bub` 命令会退出，并提示安装 `bub[app]`。

<a id="agent-install"></a>

## 构建自己的 Agent

使用 Python 3.12 或更高版本，在项目中添加 Bub：

```bash
uv add bub
uv run python -c "from bub.core import Agent; print(Agent.__name__)"
```

如果还没有项目，先运行 `uv init --python 3.12 my-agent`，再进入 `cd my-agent`。

基础安装包含内核所需的 Republic、Pydantic、Loguru 和 typing-extensions。导入检查无需模型凭据。接着阅读[构建自己的 Agent](/zh-cn/docs/sdk/)，在 Python 中配置模型并运行第一个示例。

<a id="app-development"></a>

## 在虚拟环境中开发应用

开发插件或添加追踪导出器等包时，可以创建并激活一个虚拟环境：

```bash
uv venv --python 3.12
source .venv/bin/activate
uv pip install "bub[app]"
bub --help
```

PowerShell 中的激活命令为 `.\.venv\Scripts\Activate.ps1`。在同一个环境中运行应用并安装扩展。如果项目已经使用 `uv`，也可以通过 `uv add` 添加 `"bub[app]"`，再用 `uv run bub` 运行命令。

<a id="project-dependency"></a>

## 声明包依赖

把依赖添加到项目 `pyproject.toml` 已有的 `[project]` 表。直接使用 Agent 的包声明：

```toml
requires-python = ">=3.12"
dependencies = ["bub>=0.6.0"]
```

如果包会导入内置 Agent、Framework、插件、技能或渠道，则声明：

```toml
dependencies = ["bub[app]>=0.6.0"]
```

修改依赖后，同步项目环境。现有应用更新依赖时，参照[升级到 0.6.0](/zh-cn/docs/reference/versions/)。

<a id="from-source"></a>

## 从源码参与开发

为 Bub 本身贡献代码时，克隆仓库：

```bash
git clone https://github.com/bubbuild/bub.git
cd bub
uv sync
```

`uv sync` 会安装开发依赖组，其中包含应用依赖和 Python 检查工具。之后可以使用 `uv run bub` 和仓库的测试命令。
