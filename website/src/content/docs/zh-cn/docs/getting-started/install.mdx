## 安装 CLI 应用

<Tabs syncKey="bub-app-install">
<TabItem label="macOS / Linux">

```bash
curl -fsSL https://bub.build/install.sh | bash
```

</TabItem>
<TabItem label="Windows">

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://bub.build/install.ps1 | iex"
```

</TabItem>
<TabItem label="uv">

```bash
uv tool install "bub[app]"
uv tool update-shell
```

</TabItem>
</Tabs>

运行上述脚本会帮你安装 uv 和 Python 3.12，并把 `bub[app]` 到当前环境中。

完成后在命令中执行 `bub --help` 并用 `bub onboard` 开始配置以确认命令行是否能正常工作。

<Aside type="tip">
    如果当前环境提示找不到命令，请检查环境变量是否包含了可执行文件所在路径，或者手动把 `~/.local/bin` 加入 PATH。
</Aside>

## 安装 SDK

自 0.6.0 起，Bub 默认只包含核心，可以根据使用对应包管理工具将 Bub 作为依赖安装到项目中。这里以 uv 为例：

```bash
uv add bub
uv run python -c "from bub.core import Agent; print(Agent.__name__)"
```

## 从源码运行

克隆项目仓库，按如下步骤同步依赖即可：

```bash
git clone https://github.com/bubbuild/bub.git
cd bub
uv sync
```

之后执行 `uv run bub` 运行即可。
