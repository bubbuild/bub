skill 为 Bub 提供完成特定任务的指令。这个例子会让它在修改代码前先了解仓库结构。

使用[首次运行 Bub](/zh-cn/docs/getting-started/first-turn/)中准备的工作区。每个 skill 包含一个 `SKILL.md` 文件，也可以在旁边放置脚本或参考资料。

## 编写指令

创建 skill 目录：

```bash
mkdir -p .agents/skills/repo-map
```

创建 `.agents/skills/repo-map/SKILL.md`：

```markdown
---
name: repo-map
description: 修改代码前，先阅读本地仓库结构。
---

1. 运行 `rg --files`，查看仓库结构。
2. 阅读能够说明本次修改的文件。
3. 编辑代码前，说明会涉及哪些模块。
```

`name` 必须与目录名一致，使用连字符分隔的小写单词。description 帮助模型判断何时使用这个 skill。

## 检查能否加载

```bash
bub run ",skill name=repo-map"
```

命令会打印 skill 的指令，不调用模型。如果返回 `(no such skill)`，检查文件路径和 YAML frontmatter。

## 在对话中使用

配置好模型后，运行：

```bash
bub run '使用 $repo-map skill，然后列出你找到的顶层模块。'
```

`$repo-map` 会把该 skill 的指令加入本轮系统提示词。模型随后使用应用中可用的工具执行这些步骤。这个例子需要在执行环境中安装 `rg`。

你可以把 skill 留在项目中，也可以[打包分享给其他人](/zh-cn/docs/build/skills/)。打包指南还会说明发现顺序和配套文件的用法。
