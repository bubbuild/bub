Bub 是一个由 Python 构建的轻量级 Agent 运行时。它自带一个开箱即用的 CLI 应用，也提供了一个可自由组合的 SDK，方便你在自己的程序中嵌入 Agent 能力。

Agent 的本质是一个循环：模型读取上下文并决定调用哪个工具，工具的结果写回上下文，再交给模型；当模型不再请求工具、直接给出答案时，循环结束。

构成一个 Agent 的核心有四个：**模型**、**工具**、**上下文**，以及驱动它们的**循环**。所以在这样的共识下 Bub 设计了精简的内核，并围绕内核构建出了一个开箱即用的应用。

<CardGrid>
  <Card title="核心层" icon="puzzle">
    提供可自由组合的 Agent 能力，如循环、工具、上下文、事件总线、模型客户端等。
  </Card>
  <Card title="应用层" icon="rocket">
    在核心层之上的 Harness，提供配置、插件、hooks、技能、消息渠道、网关等能力。
  </Card>
</CardGrid>

如何选择？

- 如果你想**把 Bub 与你现有的代码库或服务相结合**，那么请直接使用 Bub 核心层的 [SDK](/zh-cn/docs/sdk/)；
- 如果你想**开箱即用 Bub**，那么请直接使用 Bub 应用层的 [App](/zh-cn/docs/app/workspace/)。

:::tip
二者并不互斥，必要时你甚至可以在 SDK 中[复用 Bub 应用](/zh-cn/docs/integrations/reuse-app/#model-stage)。
:::

## 特性 {#features}

Bub 秉持着简单、可组合、可扩展的设计理念，意味着你可以自由组合 Bub 的能力，或在 Bub 的基础上构建自己的 Agent，所以 Bub 有以下特性：

<CardGrid>
  <Card title="追加式上下文" icon="database">
     会话内容以追加方式（append-only）写入 [tape](/zh-cn/docs/concepts/tape)，不修改已有记录。
  </Card>
  <Card title="事件驱动" icon="analytics">
    每次一模型与工具调用的发出开始、结束和结果都以事件形式被观测、改写或介入。
  </Card>
  <Card title="工具即函数" icon="code-branch">
    工具以函数形式存在，直接使用 Python 原生代码驱动，复用社区生态能力。
  </Card>
  <Card title="插件化" icon="setting">
    能力可以通过插件进行扩展。插件可以是一个工具、事件监听器、消息渠道，或完整的技能集合。
  </Card>
</CardGrid>

:::tip
查阅 [Agent 循环](/zh-cn/docs/concepts/agent/)以了解 Bub 的核心执行模型。
:::
