把 Agent 接入自己的 Python 程序，或从现成的 Bub 应用开始定制。Bub 应用使用同一个 Agent 内核，并提供配置、插件和渠道接入。

## 使用 Bub 应用

先运行 Bub，再通过配置和插件添加需要的行为。这条路线也包含 skills、渠道和部署。

从[运行第一轮对话](/zh-cn/docs/app/first-session/)开始；应用跑通后，到[使用 Bub 应用](/zh-cn/docs/app/)选择下一步要扩展的部分。

## 构建你的 Bub Agent

选择模型和工具，用 `bub.core.Agent` 组合 Agent，再接入自己的程序。先定义一个查询订单状态的工具，让 Agent 调用一次。

[构建你的 Bub Agent](/zh-cn/docs/sdk/)会带你跑通这个 Python 示例。需要 HTTP 接口时，继续阅读 [FastAPI 接入](/zh-cn/docs/sdk/web-service/)。

## 用到时，再查共同机制

工具、会话历史和事件的工作方式共用一份[说明](/zh-cn/docs/concepts/)。各自的指南给出接入步骤和默认行为。

按所选路线[安装 Bub](/zh-cn/docs/getting-started/install/)，然后运行第一个示例。
