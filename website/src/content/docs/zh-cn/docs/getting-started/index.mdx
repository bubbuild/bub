Bub 是一个由 Python 构建的轻量级 Agent 运行时。它自带一个开箱即用的 CLI 应用，也提供了一个可自由组合的 SDK，方便你在自己的程序中嵌入 Agent 能力。

Agent 的本质是一个循环：模型读取上下文并决定调用哪个工具，工具的结果写回上下文，再交给模型；当模型不再请求工具、直接给出答案时，循环结束。

构成一个 Agent 的核心有四个：**模型**、**工具**、**上下文**，以及驱动它们的**循环**。围绕这四个核心部件，Bub 设计了精简的内核，并构建出一套开箱即用的应用：

<CardGrid>
  <Card title="核心层" icon="puzzle">
    可组合的 Agent 内核，包含循环、工具、上下文（Tape）、事件总线和模型客户端。
  </Card>
  <Card title="应用层" icon="rocket">
    核心层之上的完整应用，提供配置、插件、Hooks、技能、消息渠道和网关。
  </Card>
</CardGrid>

如何选择？

- 如果你想**把 Bub 嵌入现有的代码库或服务**，可以直接使用核心层的 [SDK](/zh-cn/docs/sdk/)；
- 如果你想**开箱即用 Bub**，直接使用应用层的 [CLI 应用](/zh-cn/docs/app/workspace/) 即可。

:::tip
二者并不互斥，必要时你甚至可以在 SDK 中按需[复用 Bub 应用层能力](/zh-cn/docs/integrations/reuse-app/#model-stage)。
:::

## 特性 {#features}

Bub 秉持着简单、可组合、可扩展的设计理念——你可以自由组合它的能力，也可以在它之上构建属于自己的 Agent。它有以下几个核心特性：

<CardGrid>
  <Card title="追加式上下文" icon="database">
    会话记录以追加（append-only）方式写入 [Tape](/zh-cn/docs/concepts/tape/)，不修改已有记录。
  </Card>
  <Card title="事件驱动" icon="analytics">
    模型与工具调用的每个阶段都会触发事件，支持观测、改写参数或拦截执行。
  </Card>
  <Card title="工具即函数" icon="code-branch">
    用普通 Python 函数定义工具，直接复用现有 Python 生态。
  </Card>
  <Card title="插件扩展" icon="setting">
    通过插件扩展工具、事件处理器、消息渠道和技能。
  </Card>
</CardGrid>

:::tip
查阅 [Agent 循环](/zh-cn/docs/concepts/agent/)，进一步了解 Bub 的核心执行模型。
:::
