按你使用 Bub 的方式选择接入指南。每篇指南会说明所需组件，并给出检查结果的方法。

## 构建自己的 Agent

- [用 FastAPI 提供 Agent 服务](/zh-cn/docs/sdk/web-service/)：把 `core.Agent` 接入 HTTP 服务，由服务管理会话存储。

## 定制 Bub 应用

这些指南使用应用的 CLI、配置或插件机制。先[安装 Bub 应用](/zh-cn/docs/getting-started/install/)，把 Bub 和插件放在同一个环境中。

- [连接 MCP 服务器](/zh-cn/docs/integrations/mcp/)：调用 MCP 服务器提供的工具。
- [加载 Agent Plugins](/zh-cn/docs/integrations/agent-plugins/)：加载包含技能和 MCP 服务器的可移植插件包。
- [接入 ACP 编辑器](/zh-cn/docs/integrations/acp/)：在 Zed 等编辑器中使用 Bub。
- [使用本地 llama.cpp 模型](/zh-cn/docs/integrations/local-models/)：让应用调用本地模型服务。
- [把会话历史存入 SQLite](/zh-cn/docs/integrations/storage/)：通过插件替换应用的文件存储。
- [检查会话记录和执行轨迹](/zh-cn/docs/integrations/observability/)：查看本地记录，或将轨迹导出到 Phoenix 和 Logfire。
- [WASM 插件](/zh-cn/docs/app/plugins/#wasm-plugins)：用 Go 或 Rust 写 hook，通过 WebAssembly 运行。

各集成指南都提供插件文档链接，可据此查看该插件的具体配置方式。
