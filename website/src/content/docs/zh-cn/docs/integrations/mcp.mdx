通过 `bub-mcp` 插件，可以把 MCP 服务器提供的工具接入 Bub 应用。下面用一个时间服务器完成安装、连接和调用。

开始前，先[安装 Bub 应用](/zh-cn/docs/getting-started/install/#app-install)，并确保 `PATH` 中有 [`uvx`](https://docs.astral.sh/uv/)，用于启动 [`mcp-server-time`](https://pypi.org/project/mcp-server-time/)。

<Steps>

1. **安装插件**

   ```bash
   bub install bub-mcp@main
   bub hooks
   ```

   `bub install` 会从 [`bub-contrib`](https://github.com/bubbuild/bub-contrib) 解析 `bub-mcp@main`。`bub hooks` 应显示：

   ```text
   load_state: builtin, mcp
   provide_channels: builtin, mcp
   register_cli_commands: builtin, mcp
   ```

   没有 `mcp` 时，检查插件是否装进了当前 `bub` 使用的环境。

2. **注册时间服务器**

   `bub-mcp` 从 `~/.bub/mcp.json` 读取服务器定义；设置 `BUB_HOME` 时，改读 `$BUB_HOME/mcp.json`。

   ```bash
   mkdir -p ~/.bub
   cat > ~/.bub/mcp.json <<'EOF'
   {
     "mcpServers": {
       "time": {
         "command": "uvx",
         "args": ["mcp-server-time"]
       }
     }
   }
   EOF
   ```

   stdio 服务器需要 `command`，`args` 和 `env` 可选。存在 `command` 时会使用 stdio，不需要 `transport` 字段。

3. **验证连接**

   ```bash
   bub mcp list
   ```

   预期输出：

   ```text
   🔌 MCP Tools
   - time
     Status: Connected
     Tools: mcp.time_get_current_time, mcp.time_convert_time
   ```

   每个远程工具会以 `mcp.<server>_<tool>` 的名称暴露给 Bub。模型默认延迟加载完整工具定义，需要时先调用 `tool.describe`；设置 `BUB_MCP_DEFERRED_TOOLS=false` 可以让所有定义直接进入提示词。

   如果显示 `Status: Disconnected`，先在 Bub 之外运行 `uvx mcp-server-time` 排查启动问题，按 `Ctrl-C` 终止。

4. **在 Turn 中调用工具**

   MCP 工具由 `mcp.lifecycle` 维持连接。`bub chat` 和 `bub gateway` 会启动它，`bub run` 不会。

   ```bash
   bub chat
   ```

   等待几秒让 MCP 完成握手，然后输入：

   ```text
   现在 UTC 时间是多少？
   ```

   模型应调用 `mcp.time_get_current_time`。也可以直接调用工具，不经过模型：

   ```text
   ,mcp.time_get_current_time timezone=UTC
   ```

   第一轮对话可能早于工具就绪。模型没有调用工具时，先用 `bub mcp list` 检查连接，再明确要求它使用时间工具。

</Steps>

长期部署使用[网关](/zh-cn/docs/app/gateway/)或[容器](/zh-cn/docs/app/deploy/)。例如 `bub gateway --enable-channel telegram` 仍会自动启动 `mcp.lifecycle`，除非显式传入 `!mcp.lifecycle`。

## 添加其他服务器

在 `mcpServers` 下追加条目。HTTP 和 SSE 使用 `url`，并可选择 `headers`：

```json
{
  "mcpServers": {
    "weather": {
      "url": "https://weather.example.com/mcp",
      "transport": "http"
    },
    "events": {
      "url": "https://events.example.com/mcp",
      "transport": "sse",
      "headers": { "Authorization": "Bearer token" }
    }
  }
}
```

另一个 stdio 示例，通过 `npx` 启动文件系统服务器：

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/tmp"]
    }
  }
}
```

允许访问的目录写入 `args`，凭据通过 `env` 传入。保存后执行 `bub mcp list` 检查连接。

### 使用 CLI 管理

也可以用 `bub mcp add` 修改同一份配置：

```bash
# stdio
bub mcp add --transport stdio time -- uvx mcp-server-time
bub mcp add --transport stdio --env API_KEY=secret example -- node ./my-server.js

# HTTP / SSE
bub mcp add --transport http weather https://weather.example.com/mcp
bub mcp add --transport sse --header "Authorization: Bearer token" \
  events https://events.example.com/mcp

# 移除
bub mcp remove time
```

`--env` 仅用于 stdio，`--header` 仅用于 HTTP 或 SSE。

## 与可移植插件一起使用

[Agent Plugins](/zh-cn/docs/integrations/agent-plugins/) 也可以携带 MCP 服务器。两份配置分别使用独立的生命周期渠道和工具名称，可以同时运行，互不影响。

## 故障排查

| 现象 | 检查项 |
| --- | --- |
| `bub hooks` 中没有 `mcp` | 用当前 `bub` 所在环境重新安装插件 |
| `Status: Disconnected` | 在 Bub 之外直接运行 `command`，或访问 `url` |
| `bub mcp add` 在写入后打印 `CancelledError` | 条目可能已经保存；用 `bub mcp list` 复核 |
| Turn 中工具未出现 | 使用 `bub chat` 或 `bub gateway`，确认未排除 `mcp.lifecycle` |
| `mcp.json` 权限被拒绝 | 确认 `~/.bub/` 可写，或将 `BUB_HOME` 设到当前用户拥有的目录 |
