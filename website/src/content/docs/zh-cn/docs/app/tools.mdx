工具让 Bub 能够执行读写文件、运行命令和管理会话等外部操作。

## 内置工具 {#builtin-tools}

Bub 应用自带以下内置工具：

| 类别 | 工具 | 用途 |
| --- | --- | --- |
| **进程管理** | `bash` | 执行 Shell 命令；支持指定工作目录、超时和后台运行 |
| | `bash.output`、`bash.kill` | 增量读取后台进程输出，或终止后台进程 |
| **文件操作** | `fs.read`、`fs.write`、`fs.edit` | 按行读取文件（或读取图片）、覆盖写入文件、精确替换文本 |
| **网页抓取** | `web.fetch` | 发送 HTTP GET 请求抓取网页（优先请求 Markdown） |
| **能力发现** | `skill` | 列出已发现的技能，或读取指定技能的 `SKILL.md` 正文 |
| | `tool.describe` | 按需加载延迟工具（`deferred=True`）的完整参数定义 |
| **会话管理** | `tape.info`、`tape.search` | 查看会话统计与 Token 用量，或检索会话历史 |
| | `tape.handoff`、`tape.reset` | 前移上下文起点，或备份并重置会话历史 |
| | `spill.read` | 分块读取超出长度阈值的大型工具输出 |
| **子 Agent**| [`subagent`](/zh-cn/docs/app/subagents/) | 将子任务委派给后台运行的子 Agent |
| | `subagent.wait`、`subagent.send`、`subagent.cancel` | 等待子任务结果、追加指令或取消子任务 |
| **代码模式** | `run_code` | 开启代码模式时，通过执行 Python 代码组合调用多个工具 |

完整参数与返回值说明见 [内置工具参考](/zh-cn/docs/reference/tools/)。

## 调用方式 {#instructions}

在 Bub 应用中，工具有两种调用方式：

1. **模型自动调用**：在对话中正常提问，模型会根据任务和工具描述自动选择并调用工具。
2. **命令行直接调用**：使用命令前缀（默认 `,`）直接执行工具，不调用模型、不消耗 Token：
   ```bash
   bub run ",fs.read path=README.md"
   ```

如需约束模型使用工具的方式：
- **项目级规则**：在工作区根目录的 `AGENTS.md` 中编写通用规范；
- **固定流程**：将多步操作编写为[技能](/zh-cn/docs/app/skills/)，指导模型按步骤调用工具。

## 代码模式 {#code-mode}

处理复杂控制流或批量数据时，让模型多次往返调用工具会消耗大量上下文。开启代码模式后，模型会通过 `run_code` 工具直接编写一段 Python 代码，在一次执行中组合调用多个工具：

```text
,code_mode enable=true
```

- 该设置从下一轮对话起生效，并保存在当前会话的 Tape 中。
- 输入 `,code_mode enable=false` 可关闭代码模式。
- 代码模式下的 Python 调用语法见 [`run_code` 参考](/zh-cn/docs/reference/tools/#run-code)。

## 执行环境与安全 {#environment}

内置的 `bash`、`fs.*` 和 `run_code` 默认在本地宿主机上以当前用户权限直接运行：

- **无默认沙箱隔离**：模型执行的命令会对本地文件系统和进程产生真实副作用。
- **权限审批与拦截**：如需在高危工具执行前进行审批或拦截，请使用[工具拦截 Hooks](/zh-cn/docs/app/plugins/#control-a-model-or-tool-call)。
- **隔离执行环境**：如需在容器或远程沙箱中执行工具，可通过插件实现 [`provide_environment`](/zh-cn/docs/reference/hooks/#provide_environment)。

## 扩展工具 {#provide-tools}

如果内置工具无法满足需求，可以通过以下方式继续扩展：

- **安装社区插件或 MCP**：从 [社区插件中心](https://hub.bub.build/) 安装工具插件，或[接入 MCP 服务器](/zh-cn/docs/integrations/mcp/)；
- **编写自定义工具插件**：用 Python 编写函数并通过 `provide_tools` 注册，见[插件与 Hooks：提供工具](/zh-cn/docs/app/plugins/#provide-tools)。
