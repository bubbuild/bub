默认情况下，Bub 会把当前目录作为工作区（Workspace），并在运行时读取其中的文件与指令。

## 配置 AGENTS.md（可选） {#prepare-workspace}

假如你还没有对应的项目，才刚开始使用 Bub，可以先新建一个目录：

```bash
mkdir hello-bub
cd hello-bub
```

然后在该目录下创建一个 `AGENTS.md` 文件，写入针对当前项目的协作规则：

```markdown title="AGENTS.md"
你是这个工作区的 Bub Agent。
编辑文件前先阅读相关代码。
回复保持简短、具体。
```

之后每当 Bub 启动对话时，都会自动读取工作区下的 `AGENTS.md` 并注入系统提示词，让模型按照这些规则回复。跑完示例后，你也可以不断去修改这个文件中的内容，看看不同规则下模型输出的差异。

:::tip
`AGENTS.md` 是由 OpenAI 发起的一种用于指导编码 Agent 的简单开放格式，就像很多项目都会有的 `README.md` 一样。详见 [AGENTS.md 规范](https://agents.md/)。
:::

## 查看可用命令 {#check-commands}

现在，你可以在工作区终端里运行以下命令，查看当前有哪些可用命令：

```bash
bub run ",help"
```

在后续的运行中，只要以 `,`（逗号）开头就会跳过模型、直接执行对应的内置命令或工具。当然，你也可以通过 [`BUB_COMMAND_PREFIX`](/zh-cn/docs/reference/settings/#command-prefix) 把它修改成你喜欢的字符。
