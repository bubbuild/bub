title: 工作区

---

默认情况下，Bub 在一个工作区（Workspace，即目录）中运行并浏览有关于当前工作区的文件信息或指令。

## 准备工作区（可选） {#prepare-workspace}

假如你还没有对应的项目，才刚开始使用 Bub，那么可以先新建一个目录：

```bash
mkdir hello-bub
cd hello-bub
```

然后在该目录下创建一个 `AGENTS.md` 文件，并将如下内容写入当中。

```
你是这个工作区的 Bub agent。
编辑文件前先阅读相关内容。
回复保持简短、具体。
```

之后每当 Bub 运行时，会从该指令中读取相应的规则，以便模型能够按照规则输出相应内容。在示例之后，你也可以自己不断去修改这个文件中的内容，然后看看不同规则下，模型输出的差异。

:::tip
`AGENTS.md` 是由 OpenAI 发起的一种用于指导编码代理（Agent）的简单开放格式，就好像很多项目都会有的 `README.md` 文件一样。点击以了解更多有关于 [AGENTS.md](https://agents.md/) 的介绍。
:::

## 检查命令 {#check-commands}

现在你可以在一个工作区中试着在终端命令行上试着查看 Bub 有哪些命令：

```bash
bub run ",help"
```

在后续的运行中，只要以 `,` 逗号开头的前缀会调用相关命令，当然你可以通过[配置项](/zh-cn/docs/reference/settings/#agent-settings)将其修改成你喜欢的字符。
