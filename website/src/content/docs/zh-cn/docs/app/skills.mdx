[技能](https://agentskills.io/)（Skill）是由 Anthropic 发起的一项开放标准格式，用于扩展 Agent 的专业知识与任务流程。一个技能就是一个包含 `SKILL.md` 文件的目录，里面写清楚某类任务该怎么做，模型会在需要时按需加载。

## 发现顺序与优先级 {#discovery}

Bub 按以下顺序扫描并加载技能，**同名技能以最先发现的为准**：

1. **工作区目录**：`<workspace>/.agents/skills/`（兼容旧路径 `.agent/skills/`）
2. **用户全局目录**：`~/.agents/skills/`
3. **已安装的 Python 包**：环境中所有 `skills` 命名空间包（含 Bub [内置技能](#builtin-skills)）

## 内置技能 {#builtin-skills}

Bub 应用自带三个技能：

| 技能 | 用途 | 外部依赖 |
| --- | --- | --- |
| `telegram` | 发送、回复和编辑 Telegram 消息 | Telegram Bot Token |
| `gh` | 通过 GitHub CLI 管理仓库、Issue、PR 和 Actions | 安装并登录 `gh` |
| `skill-creator` | 辅助创建或更新技能 | 无 |

## 编写技能 {#write-a-skill}

你可以在当前工作区或用户全局目录下创建一个技能（`<skill-name>/SKILL.md`），例如 `.agents/skills/repo-map/SKILL.md`：

```markdown title=".agents/skills/repo-map/SKILL.md"
---
name: repo-map
description: 修改代码前，先查看本地仓库目录结构。
---

1. 运行 `rg --files` 查看仓库文件结构。
2. 阅读与本次修改相关的文件。
3. 修改代码前，先说明涉及哪些模块。
```

### 字段与变量规范 {#skill-fields}

`SKILL.md` 顶部的 YAML frontmatter 字段要求：

| 字段 | 要求 |
| --- | --- |
| `name` | **必填**。必须与所在目录名完全一致；仅限小写字母、数字和连字符，最多 64 个字符 |
| `description` | **必填**。说明适用任务与触发场景（供模型判断何时选用），最多 1,024 个字符 |
| `metadata` | 可选。字符串到字符串的键值对映射 |

辅助脚本或参考文档可放在技能目录下的 `scripts/`、`references/` 或 `assets/` 中。技能正文支持以下变量插值：

| 变量 | 展开值 |
| --- | --- |
| `$SKILL_DIR` | 当前技能目录的绝对路径 |
| `$PYTHON` | 当前运行 Bub 的 Python 解释器路径 |
| `${config.path.to.value}` | Bub 配置文件中对应点号路径的值 |

技能中的脚本不会自动运行，需在正文中指引模型调用 `bash` 等工具执行（请确保环境已安装对应命令依赖，如上例中的 `rg`）。

当然，如果你不想自己手动创建技能，也可以直接让 Bub 用内置的 `$skill-creator` 技能帮你生成：

```bash
bub run '使用 $skill-creator 技能创建名为 `repo-map` 的技能，流程如下：
1. 运行 `rg --files` 查看仓库文件结构。
2. 阅读与本次修改相关的文件。
3. 修改代码前，先说明涉及哪些模块。'
```

## 验证与使用 {#verify-a-skill}

创建完成后，可以通过以下方式验证并调用技能：

| 命令 | 说明 |
| --- | --- |
| `bub run ",skill"` | 列出当前工作区发现的所有技能 |
| `bub run ",skill name=repo-map"` | 查看变量展开后的技能正文（不调用模型）；若返回 `(no such skill)`，请检查目录名与 `name` 是否一致 |
| `bub run '使用 $repo-map 技能，列出顶层模块。'` | 显式将技能正文注入本轮系统提示词 |

:::note
即使提示词中不写 `$skill-name`，模型也会根据技能的 `description` 按需调用 `skill` 工具加载正文。
:::

## 随 Python 包分发 {#include-skills-in-a-wheel}

技能可以打包进 Python Wheel 随插件一起分发，目录结构与打包配置见[打包与分发](/zh-cn/docs/app/distribution/#bundle-plugins-and-skills)。
