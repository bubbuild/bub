Bub 应用提供两种终端用法：`bub chat` 用于交互式对话，`bub run` 用于执行一条消息。先[配置模型](/zh-cn/docs/app/configure/)。

## 继续一段对话

```bash
bub chat
```

每次输入会提交一条消息。按 Ctrl-D，或输入 `,quit`、`,exit` 退出。默认会话 ID 为 `cli_session`。

底部工具栏显示最近一次模型调用的输出速度。该数值包含请求延迟，不包含工具执行时间；提供商未返回用量时显示 `speed:- token/s`。

## 从 shell 执行一个任务

```bash
bub run "summarize CHANGELOG.md"
```

命令会打印渠道标记和响应内容，默认会话 ID 为 `cli:local`。要与交互式对话共用会话，请显式指定相同 ID：

```bash
bub chat --session-id cli:review
bub run --session-id cli:review "Summarize our decisions."
```

保持相同的工作区和存储配置，才能读取同一份会话历史。

## 直接执行命令

默认前缀为逗号。命令直接调用工具或 shell，跳过模型调用：

```bash
bub run ",help"
bub run ",fs.read path=README.md"
```

在交互式对话中也可以输入这些命令。Ctrl-X 切换 shell 模式，为输入自动添加命令前缀。

CLI 使用前台终端，因此网关默认不启动它。网关的渠道选择和消息合并规则见[渠道](/zh-cn/docs/app/channels/)，全部参数见 [CLI](/zh-cn/docs/reference/cli/)。
