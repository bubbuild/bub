Bub 提供两个终端命令，共享相同的模型、工具和 Tape 存储：

- `bub run`：处理单条消息并退出，适合单次任务或脚本调用；
- `bub chat`：启动交互式会话（REPL），支持多轮连续对话。

## 启动交互式会话 {#start-session}

在终端中输入以下命令即可进入交互式会话界面，输入内容并按回车发送：

```bash
bub chat
```

也可以在启动时直接带上第一条消息：

```bash
bub chat "Inspect this repository and suggest a first task."
```

输入 `,help` 查看内置命令；按 <kbd>Ctrl+D</kbd> 或输入 `,quit`、`,exit` 退出会话。

底部状态栏会显示最近一次模型调用的指标：

- `ttft`（首字等待时间）：从发出请求到收到第一个流式分片的耗时；
- `speed`（生成速度）：从收到首个分片到响应结束的平均输出速度（含思考 Token，不含 `ttft` 和工具执行时间；若提供商未返回用量则显示 `speed:- tok/s`）。

## 运行中补充指令（Steering） {#steering}

在等待模型回复或执行工具期间，如果发现它的处理方向偏离了预期，或者你想临时补充一些约束条件，不必等当前回复结束——直接在终端输入新指令并回车即可：

```text
先不要修改文件，只列出问题和建议。
```

这种在运行期间动态追加指令的机制称为 **Steering**。新消息会进入引导收件箱；当前正在执行的模型请求或工具调用不会被强制打断，Agent 会在进入下一个 Step 时读入这条新指令。

当会话正忙时，Bub 支持两种消息准入策略：

| 策略 | 生效时机 | 适用场景 |
| --- | --- | --- |
| `steer` | 注入当前 Turn 的下一个 Step；若当前 Turn 已结束，自动转为下一轮待处理消息 | 纠正方向、补充约束或提供与当前任务直接相关的新信息 |
| `follow_up` | 等当前 Turn 完整结束后，再按顺序开启新 Turn | 追加另一项独立任务 |

`bub chat` 在运行期间对普通输入默认采用 `steer` 策略。如需立即中止当前正在运行的任务，输入 `,quit`（会清空待处理队列并取消运行中的任务）。

## 查看与调整思考过程 {#reasoning}

展开或折叠模型的思考过程（仅切换终端显示，不改变模型推理强度）：

```text
,thinking
```

调整模型的推理强度（从下一轮起生效，并保存在当前会话 Tape 中）：

```text
,reasoning_effort high
```

## 指定会话 ID {#choose-session}

`bub run` 默认会话 ID 为 `cli:local`，`bub chat` 默认为 `cli_session`。通过 `--session-id` 指定相同 ID 可在两个命令间共享会话历史：

```bash
bub chat --session-id cli:echo
bub run --session-id cli:echo "Summarize what we discussed."
```

## 执行直接命令 {#commands}

以 `,`（默认命令前缀）开头的输入会跳过模型，直接调用对应工具：

```bash
bub run ",help"
bub run ",fs.read path=README.md"
```

交互式会话中也可以直接输入命令。在 `bub chat` 中，按 <kbd>Ctrl+X</kbd> 可在 Agent 模式与 Shell 模式之间切换（Shell 模式会自动为输入加上 `,` 前缀）。常用命令如下：

| 命令 | 用途 |
| --- | --- |
| `,model openai:gpt-5-mini` | 切换当前会话的模型 |
| `,reasoning_effort high` | 设置当前会话的推理强度 |
| `,code_mode enable=true` | 开启代码模式 |
| `,tape.info` | 查看条目数、anchor 与 Token 用量 |
| `,tape.search query=error` | 搜索当前会话历史 |
| `,tape.anchors` | 列出所有上下文锚点 |
| `,tape.handoff name=reviewed summary='...'` | 前移默认上下文起点并保存摘要 |
| `,tape.reset archive=true` | 备份并清空当前会话历史 |
| `,thinking` | 展开或折叠思考输出 |

注意：

- `,tape.reset archive=true` 会将主 Tape 和 Sidecar 备份到 `<BUB_HOME>/tapes/`（带 UTC 时间戳和 `.bak` 后缀），再重置并写入新的 `session/start` 锚点；不传 `archive=true` 则直接清空不备份。
- `,tape.handoff` 仅前移上下文读取起点并将 `summary` 存入 anchor 的 `state`，不会自动调用模型生成摘要。详见 [Tape](/zh-cn/docs/concepts/tape/#anchors)。

:::caution
未注册为内置工具的逗号命令会交给 `bash` 执行。输入前请确认该命令是安全的 Shell 命令。
:::

## 管理后台进程 {#background-shell}

在 `bub chat` 中，传入 `background=true` 可在后台启动长耗时进程：

```text
,bash command='npm run dev' background=true
```

命令会立即返回 `shell_id`，可用于增量读取输出或终止进程：

```text
,bash.output shell_id=bsh-12345678
,bash.output shell_id=bsh-12345678 offset=1200 limit=4000
,bash.kill shell_id=bsh-12345678
```

- `offset` 和 `limit` 按**字符数**（非行号）计算；每次读取返回的 `next_offset` 可直接作为下一次读取的 `offset`。
- 前台 `bash` 默认等待 **30 秒**（可通过 `timeout_seconds` 修改）。超时后进程不会报错退出，而是自动转为后台运行并返回 `shell_id`。应用退出时会自动清理后台进程。
