Bub 按以下优先级（从高到低）读取配置：

1. 环境变量（`BUB_` 前缀）；
2. 当前工作区的 `.env` 文件；
3. `~/.bub/config.yml`（由 `bub onboard` 生成）。

未配置的字段使用默认值。所有可用字段见 [配置项参考](/zh-cn/docs/reference/settings/)。

:::note[开始之前]
- 已[安装 Bub CLI](/zh-cn/docs/getting-started/install/#app-install)。
- 准备好模型提供商的 API Key，或通过 `bub login codex` 登录（仅限 OpenAI）。
:::

## 1. 运行配置向导 {#initial-setup}

在终端中执行下面的命令，进入交互式配置向导，完成后会自动生成 `~/.bub/config.yml`：

```bash
bub onboard
```

## 2. 检查配置文件 {#check-the-config}

现在可以检查一下生成的 `~/.bub/config.yml`，内容大概长这样：

```yaml title="~/.bub/config.yml"
model: openrouter:openrouter/free
api_key: sk-or-...
telegram:
  token: "123456789:your-telegram-bot-token"
  allow_users: "123456789,your_username"
```

:::danger
`bub onboard` 默认将 API Key 以明文写入 `~/.bub/config.yml`。若不希望在配置文件中保存明文密钥，可在向导中留空，改用环境变量传入。
:::

## 3. 使用环境变量 {#environment-variables}

常用环境变量：

| 变量 | 说明 |
|---|---|
| `BUB_MODEL` | 模型标识，格式为 `provider:model`（如 `openrouter:openrouter/free`、`codex:<model>`） |
| `BUB_API_KEY` | 当前提供商的 API Key（使用 `bub login` 时无需设置） |
| `BUB_API_BASE` | 提供商 API 地址；留空使用默认地址 |
| `BUB_HOME` | 运行时数据目录，默认 `~/.bub` |
| `BUB_<PROVIDER>_API_KEY` | 指定提供商的 API Key，如 `BUB_OPENROUTER_API_KEY` |
| `BUB_<PROVIDER>_API_BASE` | 指定提供商的 API 地址 |

完整列表见 [配置项参考](/zh-cn/docs/reference/settings/)。

## 4. 配置模型与备用模型 {#configure-models}

配置 `fallback_models` 可在主模型不可用时按顺序尝试备用模型：

```yaml title="~/.bub/config.yml" ins={2-3}
model: openai:gpt-5-mini
fallback_models:
  - openrouter:openrouter/free
```

每个候选模型对应的提供商都需要配置有效凭据。备用模型仅在建立连接或打开请求流失败时触发；一旦流已经开始输出，中途报错不会切换模型重试，以免重复执行工具产生副作用。详见[模型与 fallback](/zh-cn/docs/reference/settings/#model-routing)。

## 5. 配置 Telegram 渠道（可选） {#telegram-channel}

如果你打算把 Bub 当作一个 Telegram 机器人来使用，可以在 `.env` 中配置内置的 Telegram 渠道：

```bash title=".env"
BUB_TELEGRAM_TOKEN=123456789:your-telegram-bot-token
BUB_TELEGRAM_ALLOW_USERS=123456789,your_username
BUB_TELEGRAM_ALLOW_CHATS=-1001234567890
BUB_TELEGRAM_PROXY=http://127.0.0.1:7890   # 可选
```

详细用法见 [Telegram 网关](/zh-cn/docs/app/gateway/#telegram)。

## 6. 验证配置 {#verify}

配置完成后，现在可以试着与 Bub 对话，看看配置是否已经生效：

```bash wrap
$ bub run "Can you introduce yourself?"

[cli:local]
I'm a virtual assistant designed to support a wide range of tasks...
```
