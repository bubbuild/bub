import { Tabs, TabItem } from '@astrojs/starlight/components';

自 0.6.0 起，`bub` 包拆分为核心层与应用层：默认安装 `bub` 仅包含核心层（`bub.core`）；CLI、配置、插件、Hooks、技能、渠道和网关等应用层功能移入可选依赖 `bub[app]`。

如需使用 Bub CLI 或应用层功能，请升级并安装 `bub[app]`。

## 升级命令 {#upgrade-guide}

<Tabs>
<TabItem label="uv tool">

```bash
uv tool install --upgrade --force "bub[app]"
```

</TabItem>
<TabItem label="虚拟环境">

```bash
uv pip install --upgrade "bub[app]"
```

</TabItem>
<TabItem label="pyproject.toml">

插件或发行版请将依赖改为 `bub[app]`：

```toml title="pyproject.toml" ins="bub[app]"
dependencies = ["bub[app]>=0.6.0"]
```

</TabItem>
</Tabs>

## 验证升级 {#verify-upgrade}

升级后运行 `bub --help` 或 `bub hooks` 确认 CLI 与插件加载正常。
