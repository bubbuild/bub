你可以把 Agent 内核接入已有程序，也可以定制已经能运行的 Bub 应用。两条路线使用相同的模型与工具循环，由你选择复用多少应用能力。

## 组合程序需要的组件

`core.Agent` 接收你直接提供的模型、工具、提示词片段和 Tape 存储。一个小型 Python 服务使用内核依赖即可运行。

`BubAgent` 增加应用的默认能力：设置、skills、命令、工具选择和运行中的消息引导。`BubFramework` 在外围管理插件、消息处理和出站路由。需要复用这些行为时，可以直接使用。

[安装指南](/zh-cn/docs/getting-started/install/)说明依赖选择，[SDK 指南](/zh-cn/docs/build/sdk/)和[应用指南](/zh-cn/docs/build/)分别展示如何使用。

## 分开保存历史与构建上下文

完整会话可能比下一步需要的上下文更长。Tape 保留已经记录的历史，上下文选择器决定模型读取什么。锚点让新的上下文从指定位置开始，同时保留此前的工作。

这样既能查看保存的消息和工具结果，也能让下一次请求聚焦当前任务。历史是否持久保留仍取决于选择的存储，自定义应用状态也需要明确的保存方式。详见[会话历史与上下文](/zh-cn/docs/concepts/tape-and-context/)。

## 明确扩展改变什么

工具描述一个动作，skill 描述一种工作方法，渠道把应用接到人们工作的地方。区分这些职责，才能找到适合当前任务的修改位置。

运行时，事件提供模型与工具调用的接入点；应用 hooks 还负责配置、资源准备和消息路由。它们各自有执行顺序和错误规则，[扩展方式指南](/zh-cn/docs/concepts/surfaces/)会引导你找到对应接口。
