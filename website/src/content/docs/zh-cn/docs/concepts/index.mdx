## 几个常用术语

**Agent** 执行模型与工具循环。一轮**运行（run）**处理一个 prompt，可能包含多个模型步骤。**工具（tool）**是 Agent 可以执行的带类型动作。

**Tape** 保存会话记录，**条目（entry）**包括消息、工具调用、结果和事件。**锚点（anchor）**标记上下文的起点，**handoff** 写入新锚点。本轮可变**状态（state）**是另一个字典，由工具和处理器共用。

Bub 应用还提供用于接入 Python hooks 的**插件**、提供可复用指令的 **skills**，以及收发消息的**渠道**。[应用消息处理流程](/zh-cn/docs/concepts/turn/)将这些组件连接到 Agent 周围。
