完成[第一轮对话](/zh-cn/docs/getting-started/first-turn/)后，选择日常使用 Bub 的方式：留在终端里工作，接入 Telegram 机器人，或在服务器上运行网关。

这些指南使用 Bub 应用及其配置、插件和渠道。先按[安装指南](/zh-cn/docs/getting-started/install/)准备应用依赖。

## 选择下一步

- [配置应用](/zh-cn/docs/operate/configure/)：选择模型，设置提供商凭据。
- [接入渠道](/zh-cn/docs/operate/channels/)：选择接收消息的服务，以及消息如何合并为一轮对话。
- [使用终端](/zh-cn/docs/operate/channels/cli/)：执行一个任务，或继续交互式对话。
- [接入 Telegram](/zh-cn/docs/operate/channels/telegram/)：设置机器人，选择允许使用它的人。
- [部署应用](/zh-cn/docs/operate/deploy/)：构建容器，在重启后保留数据。
- [检查一次运行](/zh-cn/docs/tutorials/observability/)：查看会话历史，导出执行轨迹。

如果你的服务直接管理 `core.Agent`，请沿[用 FastAPI 提供 Agent 服务](/zh-cn/docs/tutorials/fastapi/)继续。该路线在 Python 中管理模型和存储。
