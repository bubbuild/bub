---
title: Upgrade to 0.6.0
description: Update application dependencies for the app extra and choose the Agent interfaces your code needs.
---

Bub 0.6.0 separates the Agent kernel's dependencies from the application's dependencies. When upgrading a CLI installation, plugin, or distribution, include the `app` extra.

## Update an application installation

For an application installed with `uv tool`:

```bash
uv tool install --upgrade --force "bub[app]"
```

For an activated application environment:

```bash
uv pip install --upgrade "bub[app]"
```

In a plugin or distribution's `pyproject.toml`, use `bub[app]>=0.6.0` in place of a plain `bub` dependency. The extra installs the dependencies required by the builtin runtime, Framework, settings, plugin hooks, skills, and channels.

Run `bub --help`, then [run a conversation](/docs/getting-started/first-turn/). Use `bub hooks` when checking that your plugins loaded.

## Choose the interfaces your code uses

| Your code | Dependency and guide |
| --- | --- |
| Supplies a model and tools directly to `core.Agent` | `bub`; [Build your own agent](/docs/build/sdk/) |
| Uses `BubAgent`, the Framework, application hooks, or channels | `bub[app]`; [Customize the Bub app](/docs/build/) |

A directly composed Agent takes its model and components in Python. The Bub application supplies its settings, skills, and tool policies through `BubAgent` and the Framework. [Tools](/docs/build/tools/) and [Agent events](/docs/concepts/events/) explain the shared contracts and the differences in default behavior.
