This page lists the public Python classes and function signatures exposed by Bub, followed by tables explaining their parameters, fields, and methods. For step-by-step usage guides, see the [SDK guide](/docs/sdk/), [Tape](/docs/concepts/tape/), [Events](/docs/concepts/events/), and [Turn](/docs/concepts/turn/).

- **`bub.core`**: Core layer containing the `Agent` loop, model client protocols, tools, Tape, and the event bus. Importing only `bub.core` never reads YAML files or `BUB_*` environment variables and does not load the CLI or plugins.
- **`bub`**: Application layer containing `BubFramework`, `BubAgent`, channels, and configuration loading. Requires [installing](/docs/getting-started/install/) the `bub[app]` optional dependency.

`republic.*` types appearing in signatures come from the underlying Republic library and are not expanded separately on this page.

## Core {#core}

### `Agent` {#agent}

```python
from bub.core import Agent

class Agent:
    tools: dict[str, Tool]
    builtin_tools: list[BuiltinTool]
    system_prompt: SystemPrompt
    events: EventBus

    def __init__(
        self,
        *,
        model: Model | None = None,
        store: TapeStore | AsyncTapeStore | None = None,
        tools: Iterable[Tool | BuiltinTool] = (),
        system_prompt: SystemPrompt | PromptSection | Iterable[PromptSection] = (),
        context: TapeContext | None = None,
        sidecars: Sequence[TapeSidecar] = (),
        max_steps: int = sys.maxsize,
        max_tool_concurrency: int | None = None,
        name: str = "agent",
        command_prefix: str | None = None,
    ) -> None: ...

    def tape(self, name: str, *, state: TurnState | None = None) -> Tape: ...

    @asynccontextmanager
    async def session(
        self,
        name: str,
        *,
        state: TurnState | None = None,
        merge_back: bool = True,
    ) -> AsyncGenerator[Tape]: ...

    @asynccontextmanager
    async def run(
        self,
        prompt: str | list[UserContent],
        *,
        model: Model | None = None,
        options: Mapping[str, Any] | None = None,
        tape: str,
        state: TurnState | None = None,
        merge_back: bool = True,
        metadata: dict[str, Any] | None = None,
    ) -> AsyncGenerator[AsyncStreamEvents]: ...

    async def start(
        self,
        prompt: str | list[UserContent],
        *,
        model: Model | None = None,
        options: Mapping[str, Any] | None = None,
        tape: str,
        state: TurnState | None = None,
        merge_back: bool = True,
        metadata: dict[str, Any] | None = None,
    ) -> AsyncStreamEvents: ...

    async def run_on(
        self,
        tape: Tape,
        prompt: list[UserContent],
        *,
        model: Model | None = None,
        options: Mapping[str, Any] | None = None,
        metadata: dict[str, Any] | None = None,
        span: Span | None = None,
        on_close: Callable[[], Awaitable[None]] | None = None,
    ) -> AsyncStreamEvents: ...

    async def run_once(
        self,
        prompt: list[UserContent] | None,
        *,
        model: Model | None = None,
        options: Mapping[str, Any] | None = None,
        tape: Tape,
        state: StreamState | None = None,
        pending: Sequence[list[UserContent]] = (),
    ) -> AsyncGenerator[StreamEvent, None]: ...

    async def run_command(self, tape: Tape, line: str) -> str: ...

    async def prepare_tools(
        self,
        tape: Tape,
        prompt: list[UserContent] | None,
    ) -> list[Tool]: ...
```

**Constructor parameters** (`Agent.__init__`):

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `model` | `Model \| None` | `None` | Default model (`republic.ChatModel` or `ModelClient`); can also be passed per `run()` call |
| `store` | `TapeStore \| AsyncTapeStore \| None` | New `InMemoryTapeStore()` | Synchronous or asynchronous session history store |
| `tools` | `Iterable[Tool \| BuiltinTool]` | `()` | Local `Tool` objects (stored in `agent.tools`) and provider-executed tools such as `republic.tools.WebSearch()` (stored in `agent.builtin_tools`); later entries override earlier ones with the same name |
| `system_prompt` | `SystemPrompt \| PromptSection \| Iterable[PromptSection]` | `()` | System prompt; rendered once per Run before the first model Step and reused by later Steps |
| `context` | `TapeContext \| None` | `default_tape_context()` | Strategy for projecting Tape entries into model context messages |
| `sidecars` | `Sequence[TapeSidecar]` | `()` | Sibling `TapeSidecar` instances mounted alongside the main Tape |
| `max_steps` | `int` | `sys.maxsize` | Maximum model Steps per Run |
| `max_tool_concurrency` | `int \| None` | `None` | Maximum concurrent local tool calls within one model response (`1` runs tools sequentially; does not coordinate concurrency across separate Runs) |
| `name` | `str` | `"agent"` | Name used for the Agent's OpenTelemetry trace span |
| `command_prefix` | `str \| None` | `None` | Direct command prefix (`None` disables commands; when enabled, must be a non-empty string with no whitespace, such as `","`) |

**Run parameters** (`Agent.run` / `Agent.start`):

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `prompt` | `str \| list[UserContent]` | Required | User prompt text or multimodal content blocks for this Run |
| `model` | `Model \| None` | `self.model` | Model connection overriding the Agent's default model for this Run |
| `options` | `Mapping[str, Any] \| None` | `None` | Generation options passed to the underlying model call (`republic.ChatOptions`, such as `max_tokens` or `reasoning_effort`) |
| `tape` | `str` | Required | Name of the conversation Tape used by this Run |
| `state` | `TurnState \| None` | `None` | Request-scoped dictionary shared by tools and event handlers during this Run |
| `merge_back` | `bool` | `True` | Whether to merge entries recorded on the Run's Tape fork back into the main Tape when the stream closes (see [forks and merges](/docs/sdk/tape/#forks-and-merges)) |
| `metadata` | `dict[str, Any] \| None` | `None` | Run metadata emitted on `RunStarted`; never enters model context |

**Methods**:

| Method | Description |
| --- | --- |
| `run(...)` | Async context manager: runs on a fork of the named Tape, automatically closing the stream and merging according to `merge_back` on exit |
| `start(...)` | Same parameters as `run(...)`, but returns `AsyncStreamEvents` directly; the caller must call `await stream.aclose()` |
| `tape(name, *, state=None)` | Returns a read-write `Tape` view for the given name without automatically writing an initial `session/start` anchor |
| `session(name, *, state=None, merge_back=True)` | Async context manager: opens a fork of the named Tape and merges it on exit according to `merge_back` |
| `run_on(tape, prompt, ...)` | Executes a Run on an already opened `Tape` instance |
| `run_once(...)` | Executes a single model Step and all tool calls requested by that response |
| `run_command(tape, line)` | Executes a direct command line without calling the model |
| `prepare_tools(tape, prompt)` | Overridable hook called once at the start of each Run to select active tools; calls outside the prepared set trigger a fresh `prepare_tools(tape, None)` lookup |

### `Tool`, `ToolContext`, and `@tool` {#tools}

```python
from bub.core import Tool, ToolContext, tool
from bub.core.tools import ToolExposure, content_result, result_content

type ToolExposure = Literal["auto", "direct", "code", "command"]

@dataclass(frozen=True)
class ToolContext:
    tape: Tape
    run_id: str | None = None
    state: dict[str, Any] = field(default_factory=dict)
    code_mode: bool = False
    command: bool = False
    events: EventBus | None = field(default=None, repr=False, compare=False)
    step_messages: list[republic.Message] = field(default_factory=list, repr=False, compare=False)
    call_id: str | None = None

@dataclass(frozen=True)
class Tool:
    name: str
    handler: Callable[..., Any]
    description: str = ""
    parameters: dict[str, Any] = field(default_factory=dict)
    context: bool = False
    exposure: ToolExposure = "auto"
    renderer: Callable[[Any], str] | None = None
    output_schema: dict[str, Any] | None = None
    deferred: bool = False

    async def run(self, *args: Any, **kwargs: Any) -> Any: ...
    def render(self, result: Any) -> str: ...
    def to_schema(self) -> dict[str, Any]: ...

    @classmethod
    def from_callable(
        cls,
        func: Callable[..., Any],
        *,
        name: str | None = None,
        description: str | None = None,
        context: bool = False,
        exposure: ToolExposure = "auto",
        renderer: Callable[[Any], str] | None = None,
        deferred: bool = False,
    ) -> Tool: ...

def tool(
    func: Callable | None = None,
    *,
    name: str | None = None,
    model: type[BaseModel] | None = None,
    description: str | None = None,
    context: bool = False,
    exposure: ToolExposure = "auto",
    renderer: Callable[[Any], str] | None = None,
    deferred: bool = False,
) -> Tool | Callable[[Callable], Tool]: ...

def content_result(content: Sequence[UserContent]) -> dict[str, Any]: ...
def result_content(result: Any) -> list[UserContent]: ...
```

**`@tool` / `Tool` parameters and fields**:

| Parameter / Field | Type | Default | Description |
| --- | --- | --- | --- |
| `func` / `handler` | `Callable[..., Any]` | Required | Synchronous or asynchronous Python callable implementing the tool |
| `name` | `str \| None` | `func.__name__` | Tool name (dots are converted to underscores in model-facing schemas) |
| `model` | `type[BaseModel] \| None` | `None` | Optional Pydantic parameter model (used with `@tool(model=...)`) |
| `description` | `str \| None` | Function docstring | Description shown to the model |
| `parameters` | `dict[str, Any]` | Derived from type annotations | JSON Schema dictionary of the tool's input parameters |
| `context` | `bool` | `False` | When `True`, Bub injects `context: ToolContext` as a keyword argument (excluded from the model-facing schema) |
| `exposure` | `ToolExposure` | `"auto"` | Where the tool is callable: `"auto"` (model, code mode, and commands), `"direct"` (model only), `"code"` (`run_code` only), or `"command"` (text commands only) |
| `renderer` | `Callable[[Any], str] \| None` | `None` | Custom serializer converting the tool return value to a string |
| `output_schema` | `dict[str, Any] \| None` | Derived from return annotation | Output JSON Schema used when generating code mode type stubs |
| `deferred` | `bool` | `False` | When `True`, only the tool name and description are shown initially; the model loads the full schema on demand via `tool.describe` |

**`ToolContext` fields**:

| Field | Type | Description |
| --- | --- | --- |
| `tape` | `Tape` | Read-write `Tape` view for the current session |
| `run_id` | `str \| None` | Unique identifier of the current Run |
| `state` | `dict[str, Any]` | Request-scoped `TurnState` dictionary |
| `code_mode` | `bool` | Whether the call originated inside code mode (`run_code`) |
| `command` | `bool` | Whether the call originated from a direct command |
| `events` | `EventBus \| None` | The Agent's `EventBus` |
| `step_messages` | `list[republic.Message]` | User messages sent by the calling model Step (recorded onto the Tape after the Step's tool calls finish) |
| `call_id` | `str \| None` | Call ID assigned by the model (calls inside code mode share the outer `run_code` call's ID) |

Use `content_result(content)` to return text together with images, audio, or video from a tool; `result_content(result)` reconstructs the multimodal content blocks during context projection (see [Media storage boundaries](/docs/sdk/tape/#media)).

### `SystemPrompt`, `PromptSection`, and `PromptContext` {#system-prompt}

```python
from bub.core import PromptContext, PromptSection, SystemPrompt

class PromptContext:

class SystemPrompt:
```

| Class / Member | Description |
| --- | --- |
| `PromptSection` | Fixed string, or a sync/async callable `(PromptContext) -> str \| None` |

### `Tape`, `TapeContext`, and Stores {#tape}


**`TapeContext` fields**:

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `anchor` | `AnchorSelector` | `LAST_ANCHOR` | Anchor filter: read entries after the latest anchor (`LAST_ANCHOR`), after a named anchor string, or pass `None` to disable anchor filtering |
| `select` | `ContextSelector \| None` | `None` | Custom projection selector `(Iterable[TapeEntry], TapeContext) -> list[republic.Message]`. Use `default_tape_context()` to replay full multi-turn conversations and tool round-trips |
| `state` | `dict[str, Any]` | `{}` | Request-scoped `TurnState` dictionary bound to this context |

**`Tape` properties and methods**:

| Property / Method | Description |
| --- | --- |
| `name` | The Tape's bound name; accessing it before calling `scoped(name)` raises `ValueError` |
| `scoped(name, context=None)` | Returns a new `Tape` bound to `name` (and an optional replacement `context`) |
| `with_context(context)` | Returns a new `Tape` with a replaced `TapeContext` |
| `query()` | Returns a `TapeQuery` bound to this Tape and store |
| `await read_messages()` | Selects entries through `TapeContext` and projects them into `list[republic.Message]` (skipping entries with `meta["context"] is False`) |
| `await handoff(*, name, state=None, **meta)` | Appends an `anchor` entry and a `handoff` event, moving the default context start forward |
| `await reset(*, state=None, keep_sidecars=())` | Clears the Tape and writes a new `session/start` anchor; resets mounted sidecars by default |
| `await info()` / `await anchors(limit=20)` | Returns `TapeInfo` statistics or a list of `AnchorSummary(name, state)` |
| `await search(query)` | Runs the given `TapeQuery` and returns matching entries |
| `await append_event(name, payload, **meta)` | Appends an `event` entry to the Tape |
| `fork_tape(merge_back=True)` | Async context manager: reads and writes on a fork, merging back into the main Tape on exit by default |

`session_tape_name(session_id, workspace)` returns a physical Tape name of the form `<workspace hash>__<session hash>`.

| Field | Type | Description |
| --- | --- | --- |
| `id` | `int` | Sequential ID assigned by the store (new entries start at `0` and are rewritten on `append`) |
| `kind` | `str` | Entry kind: `message`, `system`, `anchor`, `tool_call`, `tool_result`, `error`, or `event` |
| `payload` | `dict[str, Any]` | Entry payload dictionary |

| `date` | `str` | ISO 8601 timestamp string, defaulting to current UTC time |

#### `TapeStore` and `AsyncTapeStore` {#tape-store}

```python
from bub.core.store import AsyncTapeStore, TapeStore, is_async_tape_store

class TapeStore(Protocol):
    def list_tapes(self) -> list[str]: ...
    def reset(self, tape: str) -> None: ...
    def fetch_all(self, query: TapeQuery) -> Iterable[TapeEntry]: ...
    def append(self, tape: str, entry: TapeEntry) -> None: ...

class AsyncTapeStore(Protocol):
    async def list_tapes(self) -> list[str]: ...
    async def reset(self, tape: str) -> None: ...
    async def fetch_all(self, query: TapeQuery) -> Iterable[TapeEntry]: ...
    async def append(self, tape: str, entry: TapeEntry) -> None: ...

def is_async_tape_store(store: TapeStore | AsyncTapeStore) -> TypeIs[AsyncTapeStore]: ...
```

| Method | Contract |
| --- | --- |
| `list_tapes()` | Returns existing session Tape names (internal physical tapes such as sidecars need not be listed) |
| `append(tape, entry)` | Appends an entry and assigns an `id` starting at `1` and increasing monotonically within that Tape |
| `fetch_all(query)` | Returns entries matching `TapeQuery` in recording order (the async version is `async def` returning `Iterable`, not an async generator) |
| `reset(tape)` | Clears the Tape's records and resets its ID counter so the next `append` starts at `1` |

#### `TapeQuery` {#tapequery}

```python
@dataclass(frozen=True)
class TapeQuery[T: TapeStore | AsyncTapeStore]:
    tape: str
    store: T

    def query(self, value: str) -> Self: ...
    def after_anchor(self, name: str) -> Self: ...
    def last_anchor(self) -> Self: ...
    def between_anchors(self, start: str, end: str) -> Self: ...
    def between_dates(self, start: str | date_type, end: str | date_type) -> Self: ...
    def kinds(self, *kinds: str) -> Self: ...
    def limit(self, value: int) -> Self: ...

    @overload
    def all(self: TapeQuery[TapeStore]) -> Iterable[TapeEntry]: ...
    @overload
    async def all(self: TapeQuery[AsyncTapeStore]) -> Iterable[TapeEntry]: ...
```

| Method | Filter semantics |
| --- | --- |
| `query(value)` | Case-insensitive substring match against the JSON text of entry `kind`, `date`, `payload`, and `meta` |
| `after_anchor(name)` / `last_anchor()` | Entries strictly after the named or latest anchor (excluding the boundary anchor itself); raises `BubError(kind=NOT_FOUND)` if missing |
| `between_anchors(start, end)` | Entries between two anchors, excluding both boundaries; raises `BubError(kind=NOT_FOUND)` if either is missing |
| `between_dates(start, end)` | Inclusive ISO date or time range; a date-only upper bound covers the full day |
| `kinds(*kinds)` | Entries matching the specified kinds |
| `limit(value)` | Maximum number of entries returned (applied after all other filters) |
| `all()` | Executes the query (returns `Iterable` for sync stores; must be awaited for async stores) |

#### Events at a glance {#event-reference}

| Event | When it fires | What a handler can read or change |
| --- | --- | --- |
| `RunStarted` | A model Run begins | `model`, `prompt`, `metadata`, `tape`, `state` |
| `RunFinished` | The Run's stream closes | `status` (`ok` / `error` / `cancelled`), `steps`, `elapsed_ms`, `error` |
| `StepStarted` | A Step begins | `step`, optional `prompt` |
| `StepFinished` | A Step ends | `step`, `status`, `elapsed_ms`, `stream`; set `next_prompt` when continuing |
| `MessagesPending` | Before building a request, or when a Step ends without tool calls | Append user content to `messages`; at Step end, appended messages continue the Run |
| `LLMCallStarted` | Before calling the model provider | Replace `request`; set `LLMCallDecision.finish(text)` |
| `LLMCallFinished` | After success or an ordinary provider failure | `request` and the aggregated `result` (`LLMCallResult`) |
| `ToolCallStarted` | Before a local tool runs | Replace `call`; set `decision` (`proceed` / `deny` / `replace`) |
| `ToolCallFinished` | Tool success, failure, denial, or replacement | `call` and `result` (assign `event.result.result` to change the model-facing result) |
| `ChatFinished` | When a Step's exchange is ready to be recorded | `new_messages`, `response_text`, `tool_calls`, `tool_results`, `usage`, `error` |
| `CommandFinished` | A direct command succeeds or fails | `line`, `name`, `status`, `elapsed_ms`, `output` |

- `RunFinished` fires when the stream closes; a Run closed before iterating ends as `cancelled` with zero steps. `LLMCallFinished` and `ToolCallFinished` do not cover every cancellation path.
- Exceeding `max_steps` (set by `BUB_MAX_STEPS` in the app) raises `max_steps_reached`.
- Direct commands emit tool events and `CommandFinished`, but no `RunStarted` or `RunFinished`.
- See [Agent events](/docs/concepts/events/#call-control) for decision semantics and [Hooks reference](/docs/reference/hooks/#event-mapping) for app-hook mapping.

#### `Environment` members {#environment-members}

| Member | Signature | Description |
| --- | --- | --- |
| `workspace` | `str \| None` | Working directory inside the environment; relative paths are rejected when `None` |
| `python` | `str` | Python executable inside the environment, `"python3"` by default (`LocalEnvironment` uses `sys.executable`) |
| `spawn` | `async (command, *, cwd=None, env=None) -> Process` | **Abstract**. Runs a string through the shell or a sequence as an argument vector; `cwd` defaults to `workspace` |

| `run_code` | `async (code, *, tools, call_tool, write) -> None` | **Abstract**. Executes model-written Python code |
| `close` | `async () -> None` | Releases environment resources; called when `framework.running()` exits |

#### `Process` {#process}

```python
class Process(abc.ABC):
    @property
    @abc.abstractmethod
    def stdout(self) -> asyncio.StreamReader: ...
    @property
    @abc.abstractmethod
    def stderr(self) -> asyncio.StreamReader: ...
    @property
    @abc.abstractmethod
    def returncode(self) -> int | None: ...

    @abc.abstractmethod
    async def wait(self) -> int: ...
    @abc.abstractmethod
    async def write_stdin(self, data: bytes) -> None: ...

    def close_stdin(self) -> None: ...
    @abc.abstractmethod
    def signal(self, *, kill: bool) -> None: ...
```

| Member | Description |
| --- | --- |
| `stdout` / `stderr` | `asyncio.StreamReader` streams |
| `returncode` | Process exit code, or `None` while running |
| `await wait()` | Waits for exit and returns the exit code |
| `await write_stdin(data)` / `close_stdin()` | Writes and flushes standard input, or closes standard input |
| `signal(*, kill)` | Requests termination of the process and its descendants (or forces termination when `kill=True`); must not raise once exited |
| `is_running()` | Whether the process or its descendants are still alive |

#### `run_code` contract {#run-code-contract}

- `code` may use top-level `await`; each tool in `tools` is exposed as `await tools.<name>(**kwargs)` forwarding to `await call_tool(name, kwargs)` (and `republic.` prefixed names are forwarded for media and model helpers).
- Standard output must be passed to `write(chunk)` immediately as produced so output survives timeouts.
- Raise `CodeFailed(error, traceback)` when the code itself raises; custom environments with a Python interpreter can reuse `bub.core.codemode.runner.run_code_in_subprocess(self, ...)`.

#### `CodeFailed` {#codefailed}

```python
class CodeFailed(Exception):
    def __init__(self, error: str, traceback: str = "") -> None: ...
```

`error` is `"<Type>: <message>"`, and `traceback` contains only the model code's own stack frames.

#### Where the environment comes from {#provide-an-environment}

The application layer caches one `Environment` per session via the `provide_environment(session_id, workspace)` hook (defaulting to `LocalEnvironment(workspace)`), stores it in `TurnState[ENVIRONMENT_STATE_KEY]`, and calls `close()` when `framework.running()` exits.

:::caution
`LocalEnvironment` executes directly on the host, and **a separate subprocess is not a security sandbox**. Implement an isolated `Environment` when running untrusted code.
:::

### `bub.application` and `bub.program_status` {#application-events}

```python
from bub.application import CommandChanged, Outcome, PromptChanged, PromptKind, WorkChanged
from bub.program_status import ProgramStatus

type Outcome = Literal["succeeded", "failed", "cancelled"]
type PromptKind = Literal["question", "permission", "auth"]

@dataclass(frozen=True)
class CommandChanged(Event):
    outcome: Outcome | None = None

@dataclass(frozen=True)
class WorkChanged(Event):
    busy: bool
    completed: Outcome | None = None

@dataclass(frozen=True)
class PromptChanged(Event):
    kind: PromptKind | None

    def __init__(self, output: TextIO | None) -> None: ...

```

These events are published on `framework.events` (independently of `agent.events`) to drive status bars and external UIs:

| Class | Fields | Description |
| --- | --- | --- |
| `CommandChanged` | `outcome` | `None` when a CLI command starts; `"succeeded"` / `"failed"` / `"cancelled"` when it ends |
| `WorkChanged` | `busy`, `completed` | Channel busy-state changes; may carry the outcome of a completed message |
| `PromptChanged` | `kind` | `"question"` / `"permission"` / `"auth"` when a modal prompt opens; `None` when it closes |
| `ProgramStatus` | `output` | Builtin terminal status handler: emits OSC 7501 states (`idle`, `working`, `blocked`, `done`, `error`) on a TTY and clears with `state=clear` when a command ends |
