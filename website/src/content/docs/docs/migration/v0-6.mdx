import { Tabs, TabItem } from '@astrojs/starlight/components';

Starting in 0.6.0, the `bub` package is split into a core kernel and an app layer: installing `bub` installs only the core kernel (`bub.core`), while the CLI, configuration, plugins, hooks, skills, channels, and gateway live in the `bub[app]` extra.

If you use the Bub CLI or app-layer capabilities, upgrade and install `bub[app]`.

## Upgrade commands {#upgrade-guide}

<Tabs>
<TabItem label="uv tool">

```bash
uv tool install --upgrade --force "bub[app]"
```

</TabItem>
<TabItem label="Virtual environment">

```bash
uv pip install --upgrade "bub[app]"
```

</TabItem>
<TabItem label="pyproject.toml">

Update dependencies in your plugin or distribution:

```toml title="pyproject.toml" ins="bub[app]"
dependencies = ["bub[app]>=0.6.0"]
```

</TabItem>
</Tabs>

## Verify the upgrade {#verify-upgrade}

Run `bub --help` or `bub hooks` to confirm the CLI and plugins load properly.
