Once you have [run your first conversation](/docs/getting-started/first-turn/), choose how you want to use Bub day to day. Keep it in the terminal, connect a Telegram bot, or run a gateway on a server.

These guides use the Bub application and its configuration, plugins, and channels. Install the application dependencies using the [installation guide](/docs/getting-started/install/).

## Choose your next step

- [Configure the app](/docs/operate/configure/): select a model and set provider credentials.
- [Connect channels](/docs/operate/channels/): choose which services receive messages and how they group them into turns.
- [Use the terminal](/docs/operate/channels/cli/): run one task or continue a conversation.
- [Connect Telegram](/docs/operate/channels/telegram/): set up a bot and choose who can use it.
- [Deploy the app](/docs/operate/deploy/): build the container and keep its data across restarts.
- [Inspect a run](/docs/tutorials/observability/): check conversation history and export execution traces.

For a service that directly owns a `core.Agent`, follow [Serve an agent with FastAPI](/docs/tutorials/fastapi/). That route manages models and storage in Python.
