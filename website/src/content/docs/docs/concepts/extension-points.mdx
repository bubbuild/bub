Start with the behavior that you want to add. A new action needs a tool. A new place to receive messages needs a channel. You can combine these capabilities, but do not give them the same job.

| You want to | Use | Where it belongs |
| --- | --- | --- |
| Let the agent read or change something | A [tool](/docs/sdk/tools/). | A shared core capability. Pass it to Agent, or register it with the app. |
| Watch or intercept a model or tool call | An [event handler](/docs/concepts/events/). | The core EventBus. App plugins can use the matching interception hooks. |
| Change which history becomes model messages | A [TapeContext](/docs/concepts/tape/#context). | Pass it to Agent, or provide it through an app hook. |
| Teach a procedure that the agent can reuse | A [skill](/docs/app/skills/). | The Bub app discovers it and loads it. |
| Change the app setup or the message processing | A [plugin](/docs/app/plugins/). | `BubFramework` and its hooks. |
| Connect a messaging service | A [channel](/docs/app/channels/). | The inbound and outbound routing of the app. |

## Tools and skills

A tool runs Python and returns a result. A skill is a directory with a `SKILL.md` file and, optionally, more files. Its instructions can tell the agent how to use tools. You write the Python functions that the instructions refer to, and you add them separately.

A plain Agent uses the tools and prompt sections that you give it. The Bub app discovers skills and reads `AGENTS.md`. See [Skills](/docs/app/skills/) and [Tools](/docs/app/tools/).

The agent can also reach a tool through a [text command](/docs/sdk/tools/#commands), or through Python that the model writes with CodeMode. All these paths use the same tool implementation.

## Messages and state

A channel delivers an inbound envelope and sends outbound envelopes. The app uses these envelopes for the content, the routing, and the session identity. Its hooks share a mutable `TurnState` dictionary for the current turn.

The [a turn](/docs/concepts/turn/) of the app prepares that state and the prompt before it calls the agent. A direct SDK caller gives the prompt and the state to Agent.

Choose the dependencies for the capabilities that you need. Then choose the interface for the host. A Python service can reuse app plugins and keep its own request handling and streams. [Reusing plugins](/docs/sdk/reuse-plugins/) shows how to use components directly and how the framework hooks fit into an embedded host.
