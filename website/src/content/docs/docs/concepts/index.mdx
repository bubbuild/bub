## A few terms

An **Agent** runs the model and tool loop. A **run** handles one prompt and may contain several model steps. A **tool** is a typed action the agent can execute.

A **Tape** holds conversation records. Its **entries** include messages, tool calls, results, and events. An **anchor** marks a starting point for building context; a **handoff** writes a new anchor. The run's mutable **state** is a separate dictionary shared with tools and handlers.

The Bub application adds **plugins**, which provide Python hooks, **skills**, which provide reusable instructions, and **channels**, which carry messages in and out. Its [turn pipeline](/docs/concepts/turn/) connects those components around the agent.
