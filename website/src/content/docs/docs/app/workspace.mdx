By default, Bub runs in a workspace—which is simply your current directory—and reads files and instructions from there.

## Configure AGENTS.md (optional) {#prepare-workspace}

If you don't have a project yet and are just getting started with Bub, create a directory first:

```bash
mkdir hello-bub
cd hello-bub
```

Then create an `AGENTS.md` file in the workspace root with rules for the project:

```markdown title="AGENTS.md"
You are the Bub agent for this workspace.
Read the relevant content before editing files.
Keep replies short and specific.
```

From then on, whenever Bub starts a session, it automatically reads `AGENTS.md` and injects it into the system prompt. After trying the example, feel free to keep tweaking this file and see how the model's replies change under different rules.

:::tip
`AGENTS.md` is a simple open format introduced by OpenAI for guiding coding agents—much like a `README.md` for AI agents. Learn more at [agents.md](https://agents.md/).
:::

## Check available commands {#check-commands}

Now try listing the built-in commands available in your workspace from the terminal:

```bash
bub run ",help"
```

From then on, any input starting with `,` (comma) skips the model and runs the command or tool directly. Of course, you can change it to any character you like via [`BUB_COMMAND_PREFIX`](/docs/reference/settings/#command-prefix).
