title: Packaging and distribution

This page covers packaging and publishing only. To reuse Bub's configuration, plugins, and complete Turns inside an existing service, see [Reuse the Bub app](/docs/sdk/reuse-app/).

This path requires the [application dependencies](/docs/getting-started/install/#app-install).

## Publish your own command {#publish-a-command}

A distribution package can provide its own command name and call the Bub entry point internally:

```python
# src/my_bub/cli.py
def main() -> None:
    from bub.__main__ import main as bub_main

    bub_main()
```

```toml
[project.scripts]
my-bub = "my_bub.cli:main"
```

After installation, users can run `my-bub chat` or `my-bub gateway`. Declare `dependencies = ["bub[app]"]`, and follow the package restructuring described in the [0.6 migration notes](/docs/migration/v0-6/).

To pin a workspace, change the current directory before calling Bub, or let users pass `--workspace`.

## Bundle plugins and skills {#bundle-plugins-and-skills}

One wheel can provide multiple entry points and skill directories:

```toml
[project.entry-points."bub"]
models = "my_bub.models"
channels = "my_bub.channels:ChannelPlugin"

[tool.hatch.build.targets.wheel]
packages = ["src/my_bub", "src/skills"]
```

Entry points follow the [plugin registration rules](/docs/app/plugins/#entry-point-forms). For the skill directory layout, see [Distribute skills with a Python package](/docs/app/skills/#include-skills-in-a-wheel).

Plugin dependencies should be declared in the distribution package. To install a plugin into the separate project that Bub manages, use [`bub install`](/docs/reference/cli/#bub-install).

## Verify before release {#verify-a-release}

Run the following checks in a separate virtual environment:

1. Install from the wheel instead of running from the source directory.
2. Run `bub hooks` and confirm that the entry points load without deprecation warnings.
3. Run `bub run` to verify the model, tools, and state.
4. Run `bub chat` to verify skills, commands, and lifecycle channels.
5. Embed it into a host service as described in [Reuse the Bub app](/docs/sdk/reuse-app/), and verify concurrency, stream closure, and shutdown cleanup.

A clean environment exposes undeclared dependencies, entry points that cannot be imported, and configuration that only works in the development directory.
