---
title: Terminal
description: Continue a conversation with bub chat or run one task from the shell with bub run.
---

The Bub app has two terminal entry points: `bub chat` for a conversation and `bub run` for one message. [Configure a model](/docs/app/configure/) before calling it.

## Continue a conversation

```bash
bub chat
```

Each input submits a message. Press Ctrl-D or enter `,quit` or `,exit` to leave. The default session ID is `cli_session`.

The toolbar shows output speed for the latest model call. It includes request latency and excludes tool execution. When the provider does not report usage, it shows `speed:- token/s`.

## Run a task from the shell

```bash
bub run "summarize CHANGELOG.md"
```

The command prints a channel label and the response. Its default session ID is `cli:local`. To share history with an interactive conversation, supply the same ID:

```bash
bub chat --session-id cli:review
bub run --session-id cli:review "Summarize our decisions."
```

Use the same workspace and storage configuration to read the same conversation history.

## Run a command directly

The default command prefix is a comma. Commands call tools or the shell without a model request:

```bash
bub run ",help"
bub run ",fs.read path=README.md"
```

You can enter these commands in an interactive conversation too. Ctrl-X toggles shell mode, which adds the command prefix to your input.

The CLI owns the foreground terminal, so the gateway excludes it by default. See [Channels](/docs/app/channels/) for gateway selection and batching, or the [CLI](/docs/reference/cli/) for every option.
