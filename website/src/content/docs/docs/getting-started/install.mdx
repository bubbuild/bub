Bub can be used as a CLI app or as a Python SDK, so pick the install path that fits your workflow.

## Install the CLI app {#app-install}

<Tabs syncKey="bub-app-install">
<TabItem label="macOS / Linux">

```bash
curl -fsSL https://bub.build/install.sh | bash
```

</TabItem>
<TabItem label="Windows">

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://bub.build/install.ps1 | iex"
```

</TabItem>
<TabItem label="uv">

```bash
uv tool install "bub[app]"
uv tool update-shell
```

</TabItem>
</Tabs>

The install script sets up `uv`, Python 3.12, and `bub[app]` for you. The `app` extra bundles application-layer capabilities such as the CLI, channels, and plugins; you do not need it if you only use the core SDK.

When it finishes, run `bub --help` to verify the install, then run `bub onboard` to configure your model.

:::tip
If `bub` is not found, check that the install directory is on your `PATH`, or add `~/.local/bin` to `PATH` yourself.
:::

## Install the SDK {#agent-install}

From 0.6.0 on, the base `bub` package ships the core kernel only. Add it to your project with your package manager—here is `uv`:

```bash
uv add bub
uv run python -c "from bub.core import Agent; print(Agent.__name__)"
```

## Run from source {#from-source}

Clone the repository and sync its dependencies:

```bash
git clone https://github.com/bubbuild/bub.git
cd bub
uv sync
```

Then run it with `uv run bub`.
