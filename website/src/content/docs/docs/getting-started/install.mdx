## Install the CLI app {#app-install}

<Tabs syncKey="bub-app-install">
<TabItem label="macOS / Linux">

```bash
curl -fsSL https://bub.build/install.sh | bash
```

</TabItem>
<TabItem label="Windows">

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://bub.build/install.ps1 | iex"
```

</TabItem>
<TabItem label="uv">

```bash
uv tool install "bub[app]"
uv tool update-shell
```

</TabItem>
</Tabs>

The script installs uv and Python 3.12, and puts `bub[app]` into your current environment.

When it finishes, run `bub --help`, then run `bub onboard` to start configuring, and confirm the command line works.

<Aside type="tip">
    If the command is not found, check whether the environment variables include the directory that holds the executable, or add `~/.local/bin` to PATH yourself.
</Aside>

## Install the SDK {#agent-install}

From 0.6.0 on, Bub ships the core only. Use your package manager to add Bub to your project as a dependency. Here is uv:

```bash
uv add bub
uv run python -c "from bub.core import Agent; print(Agent.__name__)"
```

## Run from source {#from-source}

Clone the repository and sync its dependencies:

```bash
git clone https://github.com/bubbuild/bub.git
cd bub
uv sync
```

Then run it with `uv run bub`.
