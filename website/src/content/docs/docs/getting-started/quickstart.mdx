Since 0.6.0, Bub is split into two layers—core and app—so you can pick whichever path fits how you want to use it.

This page assumes you have already [installed Bub](/docs/getting-started/install/).

## Start from the CLI {#cli}

Open your terminal and walk through these steps on the command line:

<Steps>

1. (Optional) If you have never configured Bub before, run the setup wizard first:

   ```bash
   bub onboard
   ```

2. Create a workspace directory anywhere, switch into it, and launch an interactive session with `bub chat`:

   ```bash
   mkdir hello-bub && cd hello-bub
   bub chat
   ```

   :::tip
   Run `bub --help` or see the [CLI reference](/docs/reference/cli/) for all options.
   :::

3. Now try copying and pasting the prompt below to start a conversation with Bub:

   ```shell
   Summarize the files in this directory
   ```

</Steps>

Press <kbd>Ctrl+D</kbd> or type `,quit` whenever you want to leave the interactive session.

## Run with the SDK {#sdk}

If you want to embed an Agent in your own Python project, start with the core SDK:

<Steps>

1. Create a new project and install `bub`:

   ```bash
   uv init --python 3.12 my-agent && cd my-agent
   uv add bub
   ```

2. Save the following code as `main.py`:

   ```python title="main.py" {9-11}
   import asyncio

   import republic

   from bub.core import Agent


   async def main() -> None:
       agent = Agent(system_prompt="Be concise.")
       async with republic.get_model("openai:gpt-5-mini") as model:
           async with agent.run("What can you do?", model=model, tape="demo") as stream:
               async for event in stream:
                   if event.kind == "text":
                       print(event.data.get("delta", ""), end="")


   asyncio.run(main())
   ```

   :::tip
   See the [Python API reference](/docs/reference/python-api/) for full signatures.
   :::

3. Run it with your API key:

   ```bash
   export REPUBLIC_OPENAI_API_KEY=sk-...
   uv run python main.py
   ```

</Steps>
