Since 0.6.0, Bub itself is split in two, so you can pick whichever part fits how you want to use it.

This page assumes [Bub is installed](/docs/getting-started/install/).

## Start from the CLI {#cli}

Open your terminal and work through the following steps on the command line:

<Steps>

1. (Optional) If you have never configured Bub, run this command first to finish the initial setup:

   ```bash
   bub onboard
   ```

2. Create a workspace (a directory) anywhere and switch into it, then launch an interactive session with `bub chat`:

   ```bash
   mkdir hello-bub && cd hello-bub
   bub chat
   ```

3. Now try copying and pasting the text below to have a conversation with Bub:

   ```shell
   Summarize the files in this directory
   ```

</Steps>

Press <kbd>Ctrl+D</kbd> or type `,quit` to leave the interactive session. Run `bub --help` to see the commands and options, or see the [CLI reference](/docs/reference/cli/).

## Run it with the SDK {#sdk}

If you want to embed the agent in your own Python project, start with the base SDK.

<Steps>

1. Create a new project and install Bub:

   ```bash
   uv init --python 3.12 my-agent && cd my-agent
   uv add bub
   ```

2. Save the following code as `main.py`:

   ```python
   import asyncio

   import republic

   from bub.core import Agent


   async def main() -> None:
       agent = Agent(system_prompt="Be concise.")
       async with republic.get_model("openai:gpt-5-mini") as model:
           async with agent.run("What can you do?", model=model, tape="demo") as stream:
               async for event in stream:
                   if event.kind == "text":
                       print(event.data.get("delta", ""), end="")


   asyncio.run(main())
   ```

3. Run it with your API key:

   ```bash
   export REPUBLIC_OPENAI_API_KEY=sk-...
   uv run python main.py
   ```

</Steps>

When you need to look up other APIs, see the [Python API reference](/docs/reference/python-api/).
