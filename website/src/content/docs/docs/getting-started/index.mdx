Bub is a lightweight agent runtime written in Python. It ships with a ready-to-use CLI app and a composable SDK, so you can run it out of the box or embed agent capabilities in your own programs.

An agent is at heart a loop: the model reads the context and decides which tool to call, the tool result goes back into the context, and the model reads it again. The loop ends when the model stops asking for tools and answers directly.

So an agent rests on four core parts: a **model**, **tools**, a **context**, and the **loop** that drives them. Working from that idea, Bub keeps a small core and builds a ready-to-run application around it:

<CardGrid>
  <Card title="Core layer" icon="puzzle">
    Composable agent kernel providing the loop, tools, context (Tape), event bus, and model client.
  </Card>
  <Card title="App layer" icon="rocket">
    Application harness on top of the core, providing configuration, plugins, hooks, skills, channels, and a gateway.
  </Card>
</CardGrid>

Which one should you use?

- If you want to **embed Bub in an existing codebase or service**, start with the core [SDK](/docs/sdk/).
- If you want **Bub ready to run out of the box**, use the [CLI app](/docs/app/workspace/).

:::tip
The two are not mutually exclusive. When you need to, you can even [reuse Bub app capabilities](/docs/integrations/reuse-app/#model-stage) inside an SDK service.
:::

## Features {#features}

Bub is built around simplicity, composability, and extensibility—you can combine its parts as needed or build your own agent on top of it:

<CardGrid>
  <Card title="Append-only context" icon="database">
    Conversation history is appended to the [Tape](/docs/concepts/tape/) without mutating existing entries.
  </Card>
  <Card title="Event-driven" icon="analytics">
    Every model and tool call emits events so you can observe, modify arguments, or intercept execution.
  </Card>
  <Card title="Tools are functions" icon="code-branch">
    Define tools as standard Python functions and use any library in the Python ecosystem.
  </Card>
  <Card title="Pluggable" icon="setting">
    Extend tools, event listeners, message channels, and skills through plugins.
  </Card>
</CardGrid>

Explore [The Agent loop](/docs/concepts/agent/) to see how Bub's core execution model works.
:::
