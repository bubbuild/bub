Put an agent in your own Python program, or start with the Bub application and customize it. The application uses the same agent kernel and adds configuration, plugins, and channel integration.

## Build your own agent

Choose a model and tools, assemble an agent with `bub.core.Agent`, and connect it to your program. Start by defining a tool that looks up an order, then let the agent call it.

[Build your own agent](/docs/build/sdk/) takes you through the Python example. When you need an HTTP endpoint, continue with [FastAPI](/docs/tutorials/fastapi/).

## Customize the Bub app

Run Bub, then use configuration and plugins to add the behavior you need. This route also covers skills, channels, and deployment.

[Run your first conversation](/docs/getting-started/first-turn/) gets the app running. [Customize the Bub app](/docs/build/) helps you choose what to extend next.

## Read the common explanations as you need them

Tools, conversation history, and events share one set of [explanations](/docs/concepts/). Each route gives you its own setup steps and default behavior.

[Install Bub](/docs/getting-started/install/) for your chosen route, then run its first example.
